# Agent brief：按 13 章样板改写一章知识点.md

## 必读

1. `GOLDEN_STYLE.md`（尤其「二点五、教学体验」+ 排版硬规则 + 密度 550～800）
2. 样板：`01-基础底座/13-TCP与UDP/知识点.md`（结构、嵌套列表、`#### ❓`、`- 📖 **读图**`）
3. **只改**指定路径的 `知识点.md`；不要改练习题（除非口径硬错误）

## 改写要求

- 保留：叙事主线、技术正确性、练习题交叉引用、开篇 3 行、🎯/💡/⚠️/📝/🔍、合上书、命令速查、面试锚点、易错对照、数字墙（若已有）
- 加上：嵌套列表层级、关键小节图标、每张机制图后短读图、真难点的 `#### ❓ 为什么…`
- 压缩：重复 FAQ 合并；超 800 行必须压到 ≤800
- mermaid：**禁止** `classDef`；协议/状态用标准写法
- 禁止：元叙述目录、注水、整节只有表

## 验收（写完自检）

```bash
wc -l <path>/知识点.md   # ≤800
rg -n '📖 \*\*读图\*\*|#### ❓|^## ' <path>/知识点.md
```

在回复里报告：最终行数、新增了几个 ❓、改了哪些易混点。
