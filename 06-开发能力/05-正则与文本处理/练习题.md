## Q1

**★★★★★｜grep 默认什么模式？`grep 'error+'` 为什么匹配不到 `errorr`？**

**覆盖**：核心 · 必会 · 常考

**对应**：知识点 §3.1 · 语法必会 §1

### 场景

笔试填空 + 现场排障。有人用 `grep 'error+' app.log` 找 ERROR 行，结果为空，以为日志里没有 error。

### 完整解答

**一句话**：grep 默认 **BRE**，`+` 是字面量；要 `grep -E 'error+'` 或 `grep 'error\+'`。

| 模式 | 标志 | `+` 的含义 |
|------|------|-----------|
| BRE | 无（默认） | 字面量 `+` |
| ERE | `-E` | 一个或多个前一个字符 |

```bash
grep -E 'error+' file   # 匹配 error, errorr ...
grep 'error\+' file     # BRE 下转义 + 也行
```

生产 one-liner **一律 `-E`**。RE2 vs PCRE：RE2 线性无灾难回溯；PCRE 功能全但可能回溯爆炸。

## Q2

**★★★★★｜读代码：下面正则为什么把 CPU 打满？怎么改？**

**覆盖**：核心 · 必会 · 常考

**对应**：知识点 §3.2

### 场景

活动夜几 GB 游戏 error.log 处理卡住，大厅 502 还没统计出来。同事代码：

```python
import re
pat = re.compile(r'(.*:)+$')
with open("app.log") as f:
    for line in f:
        m = pat.match(line)
        if m:
            print(m.group())
```

畸形行（超长、冒号数量异常）上 CPU 100%。

### 完整解答

**一句话**：嵌套量词 `(.+)+` / `(.*:)+` 灾难回溯；改明确字符类 + 截断超长行 + 先 grep 过滤。

改法：

```python
safe = re.compile(r'^[^:]+(:[^:]+)*$')
with open("app.log") as f:
    for line in f:
        if len(line) > 8192:
            continue
        m = safe.match(line.rstrip("\n"))
```

额外：先 `grep -E 'ERROR|FATAL|/login'` 缩小；`.*` 抽 URL 改 `[^"]*`。

## Q3

**★★★★★｜Nginx access.log，$9 是 status 还是 $10？怎么确认？**

**覆盖**：核心 · 必会 · 常用

**对应**：知识点 §3.3 · 语法必会 §3

### 场景

登录 502。有人抄博客用 `$10` 当状态码，统计显示没有 5xx。`head -1` 一看 combined 格式 status 在 `$9`。

### 完整解答

**一句话**：列号以你们 `log_format` 为准；现场 `head -1` + `awk '{print $1,$7,$9}' | head` 对列再计数。

combined 常见映射：

| 字段 | 常见列 | 示例 |
|------|--------|------|
| client IP | `$1` | 192.168.1.10 |
| 时间 | `$4` | [28/Aug/2026:10:00:01 |
| request path | `$7` | /login |
| status | `$9` | 502 |
| RT | 看 format | 可能在 `$NF` 前 |

```bash
head -1 access.log
awk '{print $1, $7, $9}' access.log | head -5

awk '$9 ~ /^5/ {count[$1]++} END {for (ip in count) print count[ip], ip}' access.log \
  | sort -rn | head -10
```

```text
192.168.1.10 /login 502
842 203.0.113.50
156 198.51.100.22
```

## Q4

**★★★★★｜用 sed 批量改 max_connections。`-i` 的风险？路径里有 `/` 呢？**

**覆盖**：核心 · 必会 · 常用

**对应**：知识点 §语法必会 §2 · 生产模板 5

### 场景

有人 `sed -i 's/100/500/g' my.cnf`，把 `port=3100`、`wait_timeout=100` 全改了。没有备份，100 台回滚靠手工。

### 完整解答

**一句话**：sed 三步——预览 diff、匹配完整键、`-i.bak`；路径含 `/` 换 `|` 分隔符。

```bash
# 1. 预览
sed 's/max_connections=100/max_connections=500/' my.cnf | diff -u my.cnf -

# 2. 备份写入
sed -i.bak 's/max_connections=100/max_connections=500/' my.cnf

# 3. 路径替换
sed 's|/var/log/nginx|/data/log/nginx|g' nginx.conf
```

多机走 Ansible / Git（见 04）。预览过了生产仍要 bak。

## Q5

**★★★★☆｜jq 列出非 Running Pod、restartCount > 0、所有容器镜像。**

**覆盖**：必会 · 常用

**对应**：知识点 §语法必会 §4 · 生产模板 4

### 场景

`kubectl get pods -A` 宽表截断镜像名；Pending Pod 上 jq 报 `null` 错误。

### 完整解答

**一句话**：kubectl `-o json` + jq 流式筛选；Pending 先判 `containerStatuses != null`。

```bash
# 非 Running
kubectl get pods -A -o json | jq -r '
  .items[]
  | select(.status.phase != "Running")
  | "\(.metadata.namespace)/\(.metadata.name)\t\(.status.phase)"
'

# 所有镜像
kubectl get pods -A -o json | jq -r '.items[].spec.containers[].image' | sort -u

# restartCount > 0
kubectl get pods -A -o json | jq -r '
  .items[]
  | select(.status.containerStatuses != null)
  | select(.status.containerStatuses[].restartCount > 0)
  | .metadata.name
'
```

```text
default/nginx-deploy-abc12    CrashLoopBackOff
registry.example.com/app:v1.2.3
nginx-deploy-abc12
```

镜像审计应对 Deployment/StatefulSet 模板。Pending 先判 `containerStatuses != null`。

## Q6

**★★★★★｜Python 用命名组提取 error log 的时间、级别、消息。search 和 match？**

**覆盖**：核心 · 必会 · 常考

**对应**：知识点 §语法必会 §5 · §3.2

### 场景

日志行前有 syslog 前缀 `[host app]:`，`re.match` 从行首匹配全部 None。改用 `.*` 抽消息，两条 ERROR 糊在一起。

### 完整解答

**一句话**：`(?P<name>...)` 命名组 + `search` 任意位置匹配；用 `[^"]*` / 明确分隔符代替贪婪 `.*`。

```python
import re

pat = re.compile(
    r'\[(?P<ts>\d{4}-\d{2}-\d{2} \d{2}:\d{2}:\d{2})\]'
    r'\s+\[(?P<level>\w+)\]'
    r'\s+(?P<msg>.*)'
)

with open("app.log") as f:
    for line in f:
        m = pat.search(line)   # search：行内任意位置
        # m = pat.match(line)  # match：只从行首——有前缀会失败
        if m:
            d = m.groupdict()
            if d["level"] in ("ERROR", "FATAL"):
                print(d["ts"], d["msg"][:100])
```

`search` 任意位置；`match` 只从行首——有 syslog 前缀会失败。`.*` 抽引号改 `[^"]*`。

## Q7

**★★★★☆｜现场 one-liner 得出 5xx Top IP，能不能直接 iptables 封禁？**

**覆盖**：必会 · 常用 · 常考

**对应**：知识点 §踩坑清单 · §必会常考

### 场景

Top 5xx IP 里有 LB 健康检查（10.0.0.5）和公司 NAT 出口（203.0.113.0/24）。有人立刻封禁，玩家登录全挂。

### 完整解答

**一句话**：one-liner **只解释现象**；封禁是变更——排除探活/NAT、走变更单、可回滚。

判断流程：

1. Top URL 是 `/login` 且 5xx 集中 → 可能上游挂，不是扫号
2. Top IP 极分散、path 随机 → 更像扫号，仍要人工确认
3. 5xx 也可能是自己服务挂了，IP 是玩家和探活

```bash
# 统计时排除已知探活网段（例子，以你们为准）
awk '$1 !~ /^10\./ && $9 ~ /^5/ {count[$1]++} END {for (ip in count) print count[ip], ip}' access.log \
  | sort -rn | head
```

结论进 Git/Runbook。封禁前确认探活/NAT；WAF 限流往往比 iptables 合适。

## Q8

**★★★★☆｜单文件 10GB access.log，统计 5xx Top IP 和每小时 QPS，内存 4GB 跳板机怎么写？**

**覆盖**：必会 · 常用 · 常考

**对应**：知识点 §3.5 · 生产模板 2/3

### 场景

有人 `sort access.log` 或 `python open().readlines()`，跳板机 OOM，SSH 断开。

### 完整解答

**一句话**：先过滤再聚合——禁止全文件 sort / 进内存；顺序 `head -1` → grep 5xx → awk 计数。

```bash
# 0. 对格式
head -1 access.log

# 1. 5xx Top IP（grep 缩小后再 awk）
grep -E 'HTTP/[0-9.]+" 5[0-9][0-9]' access.log \
  | awk '{count[$1]++} END {for (ip in count) print count[ip], ip}' \
  | sort -rn | head -10

# 2. 每小时 QPS（全量可 awk 流式，不必 grep）
awk '{k=substr($4,14,2); count[k]++} END {for (h in count) print h, count[h]}' access.log | sort -n

# 3. 压缩日志
zgrep -E 'HTTP/[0-9.]+" 5[0-9][0-9]' access.log.gz | awk '...'
```

纯过滤 grep+awk > Python 逐行。跨天 QPS：`substr($4,2,11) substr($4,14,2)` 做 key。

## Q9

**★★★★☆｜从 Git 仓库一堆 YAML 抽所有 container image。grep 为什么会漏？**

**覆盖**：必会 · 常用

**对应**：知识点 §3.4 · §踩坑清单

### 场景

`grep -rE '^image:' deploy/` 漏了：

```yaml
containers:
  - name: app
    image: registry.example.com/app:v1.2.3
```

也漏了 Helm 子 chart 里缩进不是行首的 `image:`，以及 `image: |\n  repo:tag` 多行写法。

### 完整解答

**一句话**：YAML 结构化，grep 漏缩进/多行值；用 yq 或 `yaml.safe_load` 递归找 `image` 键。

```bash
yq '.spec.template.spec.containers[].image' deployment.yaml
# Python：safe_load_all + 递归 dict 找 key "image"
```

生产审计 Deployment/StatefulSet 模板，别扫 CRD 示例。

## Q10

**★★★★☆｜笔试：手写正则（ERE）完成下列匹配。**

**覆盖**：必会 · 常考

**对应**：知识点 §3.1 · §3.2

### 场景

运维开发笔试，不允许跑代码，纸面写 regex。

### 题目

1. 匹配 access log 中 HTTP **5xx** 状态码
2. 匹配 IPv4（简化，不要求 0–255 严格）
3. 匹配非 `#` 开头且非空的配置行
4. 从 `"GET /api/v1/login?uid=1 HTTP/1.1"` 提取 path
5. 说明为何不用 `(.+)+` 匹配冒号分隔字段

### 完整解答

**一句话**：ERE 写 5xx/IP/去注释；path 用分组；嵌套量词笔试必扣分。

1. `HTTP/[0-9.]+" 5[0-9][0-9]`
2. `([0-9]{1,3}\.){3}[0-9]{1,3}`
3. `grep -vE '^\s*(#|$)'`
4. `grep -oE '"(GET|POST) (/[^? ]*)'`
5. `(.+)+` → 灾难回溯；改 `[^:]+(:[^:]+)*`

易错：IP 的 `.` 未转义；path 用贪婪 `.*`；回溯只写「慢」不写「指数级」。
