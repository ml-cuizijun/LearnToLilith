## Q1

**★★★★★｜Nginx access.log，找出 5xx 最多的 Top10 IP。**

**覆盖**：核心 · 必会 · 常用

### 场景

登录 502。有人用网上抄的 `$10` 当状态码，统计显示没有 5xx。`head -1` 一看 status 在 `$9`。

### 完整解答

先对 combined：`$1` IP，`$9` status。再计数。

```bash
awk '$9 ~ /^5/ {count[$1]++} END {for (ip in count) print count[ip], ip}' access.log \
  | sort -rn | head -10
```

JSON 行：

```bash
jq -r 'select(.status >= 500) | .client_ip' access.log | sort | uniq -c | sort -rn | head -10
```

```mermaid
flowchart LR
    A[逐行] --> B["$9 ~ /^5/"]
    B --> C["count[$1]++"]
    C --> D[END 打印 → sort -rn | head -10]
```

### 再追问

几十 GB 怎么优化？——先 `grep '" 5[0-9][0-9]'` 再 awk。压缩用 zgrep。常查走 Loki/ES。不要 `cat` 全文件进 Python list。

## Q2

**★★★★★｜用 sed 批量改 max_connections。`-i` 的风险？路径里有 `/` 呢？**

**覆盖**：核心 · 必会 · 常用

### 场景

有人 `sed -i 's/100/500/g' my.cnf`，把端口、超时里的 100 全改了。没有备份。

### 完整解答

1. 先不加 `-i` 预览，`diff` 看差异。
2. 匹配完整键：`s/max_connections=100/max_connections=500/`。
3. `-i.bak` 留备份。
4. 多文件 `find ... -exec sed -i.bak ... {} +`。
5. 多机不要裸 ssh sed，走 04 的备份+校验或 Ansible。

```bash
sed 's/max_connections=100/max_connections=500/' my.cnf | diff -u my.cnf -
sed -i.bak 's/max_connections=100/max_connections=500/' my.cnf
sed 's|/old/path|/new/path|g'
```

macOS：`sed -i '' 's/a/b/'` 或 gnu-sed。

### 再追问

预览过了，生产仍要不要 bak？——要。预览看的是你笔记本上的副本；生产文件可能被别人改过。bak 是回滚，不是不自信。

## Q3

**★★★★★｜Python 正则提取 IP、时间、状态码。search 和 match？贪婪呢？**

**覆盖**：核心 · 必会 · 常考

### 场景

日志前面有 syslog 头，`re.match` 从行首匹配，全部 None。改用 `.*` 抽引号里的请求，把两个 URL 糊成一段。

### 完整解答

```python
import re

pattern = re.compile(
    r'(?P<ip>\d+\.\d+\.\d+\.\d+)'
    r'.*\[(?P<time>[^\]]+)\]'
    r'\s+"(?P<method>\w+)\s+(?P<path>\S+)\s+(?P<proto>[^"]+)"'
    r'\s+(?P<status>\d+)'
    r'\s+(?P<size>\d+)'
)
m = pattern.search(log)   # search 任意位置；match 只从开头
```

`.*` 贪婪：吃到最后一个引号。`[^"]*` 只吃非引号：更稳更快。百万行：`compile`、`finditer`、`for line in f`。纯过滤大文件，grep+awk 往往更快。

### 再追问

IP 正则 `\d+.\d+.` 会怎样？——`.` 匹配任意字符，会误匹配。要用 `\.` 或更严的 0–255 段。日志统计用字段列更稳。

## Q4

**★★★★★｜awk 统计每小时 QPS。要每分钟呢？列偏移错了怎么办？**

**覆盖**：核心 · 必会 · 常用

### 场景

`$4` 是 `[26/Aug/2026:10:00:00`。有人 `substr($4, 2, 2)` 取到了日期。

### 完整解答

先 `awk '{print $4}' | head` 看真实下标，再 substr。小时：从 `:` 后的时开始，常见是 `substr($4, 14, 2)`。

```
  [26/Aug/2026:10:00:00
   12345678901234
               ^^ hour
```

```bash
awk '{print substr($4, 14, 2)}' access.log | sort | uniq -c
```

每分钟：`substr($4, 14, 5)` 得到 `10:00`，用数组计数再 sort。自定义 `log_format` 必须重算偏移。

### 再追问

跨时区、文件里有两天？——按完整日期+小时做 key，不要只取小时否则两天的 10 点会加在一起。

## Q5

**★★★★☆｜jq 列出非 Running 的 Pod、重启次数 >0、所有镜像。**

**覆盖**：必会 · 常用

### 场景

`kubectl get pods` 宽表截断了镜像名。要用 JSON。

### 完整解答

```bash
kubectl get pods -A -o json | jq '.items[] | {name: .metadata.name, ns: .metadata.namespace, status: .status.phase}'

kubectl get pods -A -o json | jq '.items[].spec.containers[].image'

kubectl get pods -A -o json | jq '.items[] | select(.status.phase != "Running") | .metadata.name'

kubectl get pods -A -o json | jq '.items[] | select(.status.containerStatuses[].restartCount > 0) | .metadata.name'
```

jq 流式；Python 要先 loads。巡检分级输出见 04。

### 再追问

select 里 containerStatuses 为空？——Pending 可能还没有该字段。先 `select(.status.containerStatuses != null)`。

## Q6

**★★★★☆｜提取所有 URL 并统计次数。Shell 和 Python 谁快？**

**覆盖**：必会 · 常用

### 场景

要看登录相关 path 是不是被刷。请求在引号里：`"GET /login HTTP/1.1"`。

### 完整解答

```bash
grep -oE '"(GET|POST|PUT|DELETE) [^"]+ HTTP' access.log \
  | awk '{print $2}' \
  | sort | uniq -c | sort -rn | head -20
```

```python
import re
from collections import Counter

pattern = re.compile(r'"(GET|POST|PUT|DELETE) (\S+) HTTP')
urls = []
with open("access.log") as f:
    for line in f:
        m = pattern.search(line)
        if m:
            urls.append(m.group(2))
for url, count in Counter(urls).most_common(20):
    print(count, url)
```

小文件差不多。>1GB 通常 grep/sort 更快（C）。Python 适合结构化输出和接 API。

### 再追问

query string 要不要去掉？——统计入口用 `split('?', 1)[0]`，否则每个玩家参数都是新 URL，Top 没有意义。

## Q7

**★★★★☆｜从一堆 YAML 里抽 image。grep 为什么会漏？**

**覆盖**：必会 · 常用

### 场景

`grep -rE '^image:'` 漏了 `image: |\n  repo:tag` 多行写法，漏了 Helm 缩进不是行首的 `image:`。

### 完整解答

简单扫可以 grep，不能当完整答案。用 `yq '.spec.template.spec.containers[].image'` 或 Python `yaml.safe_load` 递归找 key `image`。

生产镜像审计应对 Deployment/StatefulSet 模板，不要扫注释和 CRD 里的例子。

### 再追问

`safe_load` 碰到多文档 `---`？——`safe_load_all`。坏文件跳过并记入失败列表，不要整次扫描当成功。

## Q8

**★★★★☆｜`grep 'error+'` 匹配不到 `error`，为什么？**

**覆盖**：必会 · 常考

### 场景

笔试填空。有人以为 `+` 是「一个或多个 r」。文件里是 `error`。

### 完整解答

默认 BRE 里 `+` 常常是字面量。要用 `grep -E 'error+'` 或 `grep 'error\+'`。生产默认写 `-E`。同类坑：`()` `{}` 在 BRE 要转义。

### 再追问

要匹配字面量 `error+` 呢？——ERE 下写 `error\+` 或 `grep -F 'error+'` 固定字符串，避免正则。

## Q9

**★★★★☆｜正则回溯把 CPU 打满，日志处理卡住。怎么改？**

**覆盖**：必会 · 常用 · 常考

### 场景

`re.compile(r'(.*:)+$')` 处理畸形行，CPU 100%。活动夜几 GB 游戏日志卡住，大厅 502 还没统计出来。

### 完整解答

避免嵌套量词 `(.+)+`、`(.*)+`。改成明确字符类：`[^:]+(:[^:]+)*`。先 grep 丢掉明显坏行。超长行截断。

```python
# 炸：re.compile(r'(.*:)+$')
safe = re.compile(r'^[^:]+(:[^:]+)*$')
with open("app.log") as f:
    for line in f:
        if len(line) > 8192:
            continue
        m = safe.match(line.rstrip("\n"))
```

游戏日志：先 `grep -E 'ERROR|/login|" 5[0-9][0-9]'` 缩小，再用字符类，不要对全量跑嵌套量词。

### 再追问

能不能加超时？——Python 标准 re 不好按行超时。控制输入长度 + 写死字符类，比「再等等」靠谱。

## Q10

**★★★☆☆｜现场 one-liner 得出 Top IP 后，能不能当变更「封禁这些 IP」的依据直接上 iptables？**

**覆盖**：常用 · 常考

### 场景

Top 5xx IP 里有健康检查探活和 NAT 出口。有人立刻封禁，登录全挂。

### 完整解答

one-liner 只解释现象。封禁是变更：要确认是攻击还是共享出口/探活，走变更单，可回滚。把命令写进 Git/Runbook，不要靠 history。

5xx 多也可能是自己服务挂了，IP 是玩家和探活。先看 URL 聚合（04 Q2），再决定限流还是修服务。

```bash
# 统计时排除探活网段（例子，以你们网段为准）
awk '$1 !~ /^10\./ && $9 ~ /^5/ {count[$1]++} END {for (ip in count) print count[ip], ip}' access.log \
  | sort -rn | head
```

### 再追问

探活 IP 怎么排除？——已知 LB/探活网段写进脚本白名单。`awk '$1 !~ /^10\./'` 只是例子，以你们网段为准。
