## 三语言定位

| 语言 | 定位 | 大厂考什么 |
|------|------|------------|
| Shell | 现场排障、批量、one-liner | set -euo pipefail、并发、不可复现脚本 |
| Python | 运维工具、API、自动化 | 请求重试、并发、日志、异常 |
| Go | Exporter/Operator | 能读源码、goroutine 泄漏 |

**复习优先级：** 04 实战题 > 01 Shell > 05 正则 > 02 Python > 03 Go。
