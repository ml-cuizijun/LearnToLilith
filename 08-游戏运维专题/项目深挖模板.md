# 项目深挖模板 · 游戏运维

> **用途**：项目深挖 30～50 分钟主故事。游戏履历定级看开合服、热更、活动、回档是否真操过。**数字全是占位符 `<...>`，答题前换成你的真实值。**
>
> 口述纪律：主语「我」；每个故事 ≥2 个数字；讲权衡；能扛 3 轮追问。方法论见 [01-职业发展/02-简历与项目](../01-职业发展/02-简历与项目/)。

## 候选项目（选 2 个深挖，1 个备用）

| 方向 | 一句话电梯版 |
|------|-------------|
| **开服自动化** | 我把开服做成分段流水线，单服从 **<X min→Y min>**，失败停在门禁，未开放环境可拆，活动日并行 **<N>** 服 |
| **合服** | 我负责 **<A+B>** 服合并，**<N>** 万角色，窗口 **<T h>**，映射表留存，失败预案是双备份拉回而不是反迁 |
| **热更/发版** | 我把配置/资源/强更拆开，灰度按 **<uid/服>** ，回滚配置 **<X min>**，资源靠指针回退 |
| **活动高峰** | 我按登录/玩法/发奖三峰扩和降级，峰值 CCU **<N>**，发奖失败率 **<__%>**，有状态层预开不靠 HPA |
| **回档** | 我处理 **<误操作/数值爆炸>** ，范围 **<单号/单服>**，窗口内订单补发 **<M>** 笔，没有裸改库 |

开场 60 秒只点 2 个，考官会挑一个往下挖。合服和回档最能定 Senior，没做过不要硬编。

| 阶段 | 内容（替换占位符） |
|------|-------------------|
| **S 背景** | **<N>** 个区服，低活跃服 **<A、B>** 要合并；版本 **<__>** ，角色合计 **<M>** 万，有跨服战区 |
| **T 任务** | 我做变更负责：窗口内完成合并，可回滚，经济可对账 |
| **A 动作** | ① T-48h 公告，跨服入口先关 ② 两边版本对齐，映射脚本 dry-run ③ 停写、双备份、校验基线 ④ 按映射迁角色/公会/关系 ⑤ 计数+金额+高 V 抽样 ⑥ 只开目标服，源服标已合并 |
| **R 结果** | 窗口 **<T h>** 内开放；校验差异 **<0 / X 条已解释>**；客诉改名 **<__>** ；映射表进备份，后续工单能查旧 ID |

备用 STAR（开服）：预检→建库→部署→冒烟→**最后写目录**；失败 **<__ 次>** 都停在未开放；回滚是拆 dirty，不是对玩家致歉后再修空库。

## 高阶追问准备

| 追问 | 答法骨架 |
|------|---------|
| **合服失败怎么回滚？** | 丢弃半成品，A/B 从备份拉起，目录恢复两服；禁止反向再迁（→ 02 章） |
| **映射表丢了怎么办？** | 停一切修复，从合服备份找回；不靠角色名撞库（→ 02、07 章） |
| **有状态服为什么不能 HPA 救命？** | 新副本接不住已绑定房间，只能预开空进程+摘流（→ 01、05 章） |
| **热更能回滚客户端吗？** | 配置能回；清单指针能回；已装包的端常常只能向前发修（→ 03、06 章） |
| **活动压测绿了线上仍炸？** | 渠道鉴权、CDN 未预热、热 key、机器人不走 Tick（→ 05、06 章） |
| **回档后玩家说充值没了？** | 回档前导出窗口订单，回后补发；这是二次伤害，工单里必须有这一栏（→ 07 章） |
| **游戏 SLO 为什么不用月度可用性？** | 开服 10 分钟登不上就是 P0，30 天平均会摊平（→ 09 章） |
| **如果重来？** | 说一条你当时没坚持的否决权：版本不一致拒合、窗口不够拒上、活动日拒叠发版 |
