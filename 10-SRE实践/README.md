# 10 SRE 实践

> **给面试官看的那一层：架构取舍，不是再背一遍 kubectl。**  
> 操作细节仍在 02 / 04 / 05 / 07 / 08 / 09。这一模块只讲 SRE 怎么把可靠性做成合同、把平台做成减 Toil、把大规模系统讲成可画的图。

大厂高级运维 / SRE 面经常问的是方向，不是命令：平台怎么减人力、SLO 怎么卡发布、成本算不算稳定性、多集群 / 网格 / GPU / 有状态游戏怎么选。答「我都会装」不够，要答「为什么这样拆、不选什么、炸了先动哪一层」。
