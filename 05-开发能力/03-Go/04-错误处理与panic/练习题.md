## Q1

**★★★★★｜Go 没有 try/catch，函数失败怎么表达？`error` 是什么？**

**覆盖**：核心 · 必会 · 常考 | **对应**：知识点 [二、出生：error 接口与多返回值](知识点.md)

### 场景

Java 同事写 Go 巡检工具，想找 throw。

### 完整解答

> 🎯 **一句话**：**多返回值 `(T, error)`**；`error` 是含 `Error() string` 的**接口**；`nil` 表示成功。

```go
n, err := statDisk("/")
if err != nil {
    return err
}
_ = n
```

业务失败 **return error**，不用 panic 代替。

> 📝 **面试**：「显式 error 强制调用方处理；链式 wrap 用 %w。」

### 再追问

`error` 可以是 nil 吗？——可以，表示无错误。

## Q2

**★★★★★｜为什么 Go 代码满屏 `if err != nil`？早返回有什么好处？**

**覆盖**：核心 · 必会 | **对应**：知识点 [二、出生](知识点.md)

### 场景

深层嵌套 if 可读性差，团队要求扁平化。

### 完整解答

> 🎯 **一句话**：**早返回**避免嵌套；错误路径清晰；资源用 defer 清理。

```go
f, err := os.Open(p)
if err != nil {
    return fmt.Errorf("open: %w", err)
}
defer f.Close()
// 主逻辑左侧对齐
```

### 再追问

每个 err 都要 log 吗？——一般在**边界**（main/handler）打一次，避免重复。

## Q3

**★★★★★｜`fmt.Errorf("ctx: %v", err)` 和 `%w` 有何区别？对 `errors.Is` 的影响？**

**覆盖**：核心 · 必会 · 常考 | **对应**：知识点 [三、包装：fmt.Errorf 与 %w](知识点.md)

### 场景

包装三层后 `errors.Is(err, os.ErrNotExist)` 突然 false。

### 完整解答

> 🎯 **一句话**：**%w 保留 unwrap 链**；**%v 只拼字符串**，Is/As **失效**。

```go
// 好
return fmt.Errorf("read config: %w", err)

// 差
return fmt.Errorf("read config: %v", err)
```

### 再追问

还能用 `github.com/pkg/errors` 吗？——新项目用标准库 `%w` 即可。

## Q4

**★★★★★｜`var ErrTimeout = errors.New("timeout")`，上层如何判断？能和 `==` 直接比吗？**

**覆盖**：核心 · 必会 · 常考 | **对应**：知识点 [四、判断：errors.Is 与 errors.As](知识点.md)

### 场景

重试逻辑要认超时，不管中间包了几层。

### 完整解答

> 🎯 **一句话**：用 **`errors.Is(err, ErrTimeout)`**；有 wrap 时裸 `==` 常失败。

```go
if errors.Is(err, ErrTimeout) {
    backoff()
}
```

无 wrap 时 `err == ErrTimeout` 也可，但习惯统一 Is。

> ⚠️ **别混**：不要用 `strings.Contains(err.Error(), "timeout")`。

### 再追问

`errors.Is(err, nil)` 结果？——false（除非 err 本身 nil）。

## Q5

**★★★★☆｜要从 error 链取出 `*os.PathError` 用什么？示例？**

**覆盖**：必会 · 常考 | **对应**：知识点 [四、判断](知识点.md)

### 场景

磁盘巡检要打印具体路径。

### 完整解答

> 🎯 **一句话**：**`errors.As(err, &pe)`**，`pe` 为 `*os.PathError`。

```go
var pe *os.PathError
if errors.As(err, &pe) {
    log.Printf("path=%s op=%s", pe.Path, pe.Op)
}
```

As 第二个参数必须是**指向目标类型的指针**。

### 再追问

As 和 type switch 区别？——As 会 unwrap 链；type switch 对单层。

## Q6

**★★★★☆｜什么时候定义哨兵 `var ErrNotFound`？什么时候用自定义 struct？**

**覆盖**：必会 · 常用 | **对应**：知识点 [五、哨兵错误与自定义类型](知识点.md)

### 场景

CMDB 查无此机 vs HTTP 502 需要不同字段。

### 完整解答

> 🎯 **一句话**：**稳定、可枚举**的失败用哨兵 + Is；需要 **Code/Path/字段** 用 struct + As。

```go
var ErrNotFound = errors.New("not found")

type APIError struct { Status int; Body string }
func (e *APIError) Error() string { return fmt.Sprintf("api %d", e.Status) }
```

哨兵别泛滥，一包一个即可。

### 再追问

哨兵该 export 吗？——要跨包 Is 则大写 `ErrX`。

## Q7

**★★★★★｜打开文件后必须 `defer f.Close()`，若 Close 也失败怎么处理？**

**覆盖**：核心 · 必会 | **对应**：知识点 [六、defer：资源与 panic 清理](知识点.md)

### 场景

Write 成功但 Close 失败，数据可能未落盘。

### 完整解答

> 🎯 **一句话**：defer 里 Close，**若主 err 为 nil 则把 close err 赋给返回 err**。

```go
defer func() {
    if cerr := f.Close(); cerr != nil && err == nil {
        err = cerr
    }
}()
```

命名返回 `err` 时常用此模式。

### 再追问

循环里打开 100 个文件怎么 defer？——抽 `func processOne()` 每文件一个 defer，或不用 defer 即时 Close。

## Q8

**★★★★★｜配置文件路径写错、用户输入非法端口，该 panic 还是 return error？**

**覆盖**：核心 · 必会 · 常考 | **对应**：知识点 [七、panic 与 recover：边界](知识点.md)

### 场景

有人 `panic(err)` 在 HTTP handler。

### 完整解答

> 🎯 **一句话**：**可预期、可恢复 → return error**；**不变量/不可能分支 → panic**。

| 场景 | 选择 |
|------|------|
| 文件不存在 | error |
| 模板 parse 在 init | `template.Must` panic |
| 数组越界 bug | panic |

Handler 应 `http.Error`，别 panic 业务流程。

### 再追问

`log.Fatal` 呢？——等价 log + `os.Exit`，defer 也不跑。

## Q9

**★★★★★｜子 goroutine panic 了，主 goroutine `recover` 能抓住吗？**

**覆盖**：核心 · 必会 · 常考 | **对应**：知识点 [七、panic 与 recover](知识点.md)

### 场景

并行 scrape 一台崩全盘挂。

### 完整解答

> 🎯 **一句话**：**不能**；recover 只救**本 goroutine** 栈；子 goroutine 需**自己的 defer recover** 或 errgroup（09 章）。

```go
go func() {
    defer func() {
        if r := recover(); r != nil {
            log.Printf("worker: %v", r)
        }
    }()
    risky()
}()
```

### 再追问

`net/http` handler panic 谁 recover？——Server 默认转 500；别依赖，应 return error。

## Q10

**★★★★☆｜`defer cleanup(); os.Exit(1)` 为何 cleanup 没跑？**

**覆盖**：必会 · 常用 | **对应**：知识点 [七、panic 与 recover](知识点.md)

### 场景

CLI 检测到错误直接 Exit，临时文件没删。

### 完整解答

> 🎯 **一句话**：**`os.Exit` 立即终止进程，不跑 defer**。

修法：`run() error` 在 main 里 `if err != nil { cleanup(); os.Exit(1) }`；或不用 Exit 用 return。

### 再追问

`log.Fatal` 会跑 defer 吗？——不会。

## Q11

**★★★★★｜`cmd.Run()` 错误只 `log.Println` 不 return，CI exit 0——叫什么？怎么防？**

**覆盖**：核心 · 必会 | **对应**：知识点 [八、作战](知识点.md)

### 场景

发布脚本 kubectl 失败仍绿。

### 完整解答

> 🎯 **一句话**：**假成功**；必须 **`if err != nil { return err }`**，main 统一非零退出。

```go
if err := cmd.Run(); err != nil {
    return fmt.Errorf("kubectl: %w", err)
}
```

### 再追问

`_ = cmd.Run()` 在 lint 里？——vet 可能提示 ignored error。

## Q12

**★★★★☆｜设计巡检 CLI 错误策略：哪层 wrap、哪层 log、退出码怎么分？**

**覆盖**：常用 | **对应**：知识点 [八、作战](知识点.md)

### 场景

配置错误 vs 探测失败希望不同 exit code。

### 完整解答

> 🎯 **一句话**：底层 **%w 添上下文**；**main 一次 slog**；`Exit 2` 用法错误、`1` 运行失败（团队约定文档化）。

```go
const (
    ExitOK = 0
    ExitFail = 1
    ExitUsage = 2
)
```

可重试用 `errors.Is` 在 main 决定是否 exit 1 或重试（08 章 context）。

### 再追问

要不要每层都 `%+v` 打栈？——标准库 error 无栈；用 `log/slog` 记录 `err` 字段即可。

## Q13

**★★★★★｜白板：一个 error 从产生到 wrap 的一生。**

**覆盖**：核心 · 必会 | **对应**：知识点 [一、一张图](知识点.md)

### 场景

面试 Go 错误处理题。

### 完整解答

> 🎯 **一句话**：底层 return → 中层 `fmt.Errorf %w` → 顶层 `Is/As` 决策 → 日志与 exit。

分支：编程错误 panic；recover 仅局部安全网。

### 再追问

`errors.Join` 何时用？——多错误聚合（1.20+），如校验多个字段。

## Q14

**★★★★★｜读代码找 bug：**

```go
func load(path string) error {
    _, err := os.Open(path)
    if err != nil {
        return fmt.Errorf("load: %v", err)
    }
    return nil
}

func main() {
    err := load("/missing")
    if errors.Is(err, os.ErrNotExist) {
        fmt.Println("skip")
        return
    }
}
```

**覆盖**：核心 · 必会 | **对应**：知识点 [三、包装](知识点.md)

### 场景

想文件不存在时跳过，却总走不到 skip。

### 完整解答

> 🎯 **一句话**：`load` 用了 **%v 断了链**，`Is(err, os.ErrNotExist)` **为 false**。

```go
return fmt.Errorf("load: %w", err)
```

另：Open 后未 Close 泄漏 fd——应 defer Close 或 Read 后关。

### 再追问

若已用 %w 仍 Is 失败？——比的是 `os.ErrNotExist` 而非包装后的外层 error；确认底层确实是 PathError 包装的 ErrNotExist。
