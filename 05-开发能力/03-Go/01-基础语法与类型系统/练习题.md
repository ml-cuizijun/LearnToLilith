## Q1

**★★★★★｜`go build` 报 `package main is not in GOROOT`，新人把 `main.go` 放在仓库根目录直接编译——怎么回事？**

**覆盖**：核心 · 必会 | **对应**：知识点 [二、出生：package、import 与 main 入口](知识点.md)

### 场景

巡检工具仓库根只有 `main.go`，没有 `go.mod`；同事在子目录 `cmd/check/` 又写了一份 `package main`。CI 里路径混乱。

### 完整解答

> 🎯 **一句话**：可执行入口要 **`package main` + `func main()`**，且应在 **module 内**用 `go build ./cmd/check` 指定包路径（见 02 章）。

```go
// cmd/check/main.go
package main

func main() { /* ... */ }
```

```bash
go build -o check ./cmd/check/
```

根目录散放 `main.go` 且无 module 时，老环境可能误报 GOROOT；现代项目先 `go mod init`，入口放 `cmd/<name>/`。

> 📝 **面试**：「Go 可执行程序是 main 包；库是别的包名；构建用包路径不是单个文件名。」

### 再追问

`package main` 能被别的包 import 吗？——不能，main 仅用于生成可执行文件。

## Q2

**★★★★★｜调试时加了 `import "fmt"` 和 `import "encoding/json"`，删了打印后 CI 编译失败 `imported and not used`——为什么？**

**覆盖**：核心 · 必会 · 常考 | **对应**：知识点 [二、出生：package、import 与 main 入口](知识点.md)

### 场景

发版前有人注释掉 JSON 输出，忘了删 import，流水线 `go build ./...` 全红。

### 完整解答

> 🎯 **一句话**：Go **禁止未使用的 import**，编译期直接失败。

修法：删掉无用 import；或临时 `import _ "net/http/pprof"` 做副作用注册。IDE 保存时可用 `goimports` 自动清理。

> ⚠️ **别混**：Python 未使用 import 只是 lint 警告；Go 是硬错误。

### 再追问

未使用的**局部变量**呢？——同样编译不过，用 `_ = x` 或删掉。

## Q3

**★★★★★｜`var p *Pod`、`var n int`、`var s string` 未赋值，分别是什么？`s == nil` 合法吗？**

**覆盖**：核心 · 必会 · 常考 | **对应**：知识点 [四、类型与零值](知识点.md)

### 场景

配置解析里用 `*int` 表示「未设置超时」，有人却用 `int` 零值 0 表示「未设置」，和「真的超时 0 秒」冲突。

### 完整解答

> 🎯 **一句话**：指针/slice/map 零值为 **nil**；`int` 为 **0**；`string` 为 **`""`**，不能与 nil 比较。

```go
var p *Pod   // nil
var n int    // 0
var s string // ""

// if s == nil { }  // 编译错误：invalid operation
if s == "" { }      // 正确：空串
```

可选配置用 `*int`：`nil` = 未设置，非 nil 才读值。

### 再追问

`var m map[string]int` 能直接 `m["k"]=1` 吗？——不能，nil map 写入 panic（见 03 章）。

## Q4

**★★★★★｜`port := 8080` 与 `timeout := int64(30)`，后面 `port + timeout` 为什么编译不过？**

**覆盖**：核心 · 必会 · 常考 | **对应**：知识点 [五、基础类型与显式转换](知识点.md)

### 场景

Prometheus exporter 从 flag 读到 `int`，又要和 `int64` 的纳秒时间戳相加。

### 完整解答

> 🎯 **一句话**：Go **无隐式数值转换**，必须 `int64(port) + timeout`。

```go
port := 8080
timeout := int64(30)
sum := int64(port) + timeout
```

端口常用 `int`；与 API 交互的 ID、时间戳优先 `int64`。

> 📝 **面试**：「C/Java 部分隐式 widening；Go 必须显式，避免静默截断。」

### 再追问

`float64` 和 `int` 能相加吗？——不能，两边都要显式转。

## Q5

**★★★★☆｜下面哪行合法？`x := 1` 后 `x := 2`；`x, err := f()` 再 `x, err := g()`**

**覆盖**：必会 · 常考 | **对应**：知识点 [三、命名：var、const 与短变量声明](知识点.md)

### 场景

复制粘贴解析函数，第二行仍写 `:=` 导致编译失败。

### 完整解答

> 🎯 **一句话**：`:=` 要求左侧**至少一个新变量名**；全旧名须用 `=`。

```go
x := 1
x = 2              // OK
// x := 2          // 错误

x, err := f()
x, err = g()       // OK：err 已存在
y, err := g()      // OK：y 是新变量
```

### 再追问

包级能用 `:=` 吗？——不能，包级用 `var`。

## Q6

**★★★★★｜`func setTimeout(c Config)` 里 `c.Timeout = 60`，调用方 `cfg` 仍是 30——为什么？怎么改？**

**覆盖**：核心 · 必会 | **对应**：知识点 [六、值与指针](知识点.md)

### 场景

批量改 Nginx 上游超时，函数里改了 struct，调用方切片里的元素没变。

### 完整解答

> 🎯 **一句话**：**传值复制** struct，函数内改的是副本；要改调用方用 `*Config` 或返回新值。

```go
func setTimeout(c *Config) {
    c.Timeout = 60
}
setTimeout(&cfg)
```

大 struct 传指针也省拷贝。

> ⚠️ **别混**：Go 没有 C++ 默认引用；是否共享看类型是不是指针。

### 再追问

`slice` 传参是值还是指针？——传的是 slice 头（指针+len+cap 副本），改元素可能影响底层（03 章）。

## Q7

**★★★★★｜`json.Marshal` 后 `replicas` 字段总是缺失，struct 写的是 `replicas int`——原因？**

**覆盖**：核心 · 必会 · 常考 | **对应**：知识点 [七、结构体与导出规则](知识点.md)

### 场景

CMDB 同步脚本输出 JSON 给飞书 webhook，字段对不上。

### 完整解答

> 🎯 **一句话**：**未导出字段**（小写）`encoding/json` **不会编码**。

```go
type Deploy struct {
    Name     string `json:"name"`
    replicas int    // 改成 Replicas
}
```

跨包访问同样需要大写：`Replicas int`。

> 📝 **面试**：「导出 = 首字母大写；JSON 还要 `json` tag 控制名字。」

### 再追问

tag 写成 `json:"-"` 会怎样？——该字段永远不出现在 JSON。

## Q8

**★★★★☆｜告警标题 `len(title)` 和肉眼看到的「字数」不一致，含 emoji 时更严重——为什么？**

**覆盖**：常用 · 常考 | **对应**：知识点 [五、基础类型与显式转换](知识点.md)

### 场景

截断飞书消息用 `title[:20]` 把 emoji 截成乱码。

### 完整解答

> 🎯 **一句话**：`string` 是 **UTF-8 字节序列**；`len` 是**字节数**；按字符用 `range` 或 `utf8`。

```go
s := "告警🚨"
len(s)                    // 7 字节左右，不是 3「字」
for _, r := range s { }   // 按 rune（码点）
```

### 再追问

`[]byte(s)` 和 `string(b)` 是否零拷贝？——会分配/拷贝，热路径注意（1.20+ 部分优化了解即可）。

## Q9

**★★★☆☆｜用 `iota` 定义退出码：`ExitOK=0, ExitConfig=1, ExitProbe=2`，和 `const` 魔数比有什么好处？**

**覆盖**：常用 | **对应**：知识点 [三、命名：var、const 与短变量声明](知识点.md)

### 场景

systemd `SuccessExitStatus` 和脚本约定退出码，要可读且不重号。

### 完整解答

> 🎯 **一句话**：`iota` 在 `const` 块里**自动递增**，集中维护、避免重复赋值。

```go
const (
    ExitOK = iota
    ExitConfig
    ExitProbe
)
```

监控可按退出码聚合；别和 shell 255 语义冲突。

### 再追问

`iota` 中间插一行 `_=iota` 可跳过值吗？——可以，用于预留。

## Q10

**★★★★☆｜`cannot refer to unexported field timeout in struct literal of type config.Server`——怎么查？**

**覆盖**：必会 · 常用 | **对应**：知识点 [九、作战：读编译错误定责](知识点.md)

### 场景

在 `main` 包初始化 `config.Server{timeout: 30}` 编译失败。

### 完整解答

> 🎯 **一句话**：**跨包**不能设小写字段；用导出字段或 `config` 包提供的构造函数。

```go
// config/server.go
type Server struct { Timeout int }
func New(timeout int) Server { return Server{Timeout: timeout} }
```

决策树：undefined → import/拼写；unexported → 可见性；type mismatch → 显式转换。

### 再追问

同包能访问小写字段吗？——能，可见性是**包级**不是文件级。

## Q11

**★★★★☆｜`a, b := 1, 2` 后 `a, b = b, a` 交换，和 `tmp := a; a = b; b = tmp` 有类型问题吗？**

**覆盖**：必会 | **对应**：知识点 [六、值与指针](知识点.md)

### 场景

面试白板：Go 交换两个 `int` 要不要指针？

### 完整解答

> 🎯 **一句话**：**同类型多赋值**一次完成交换，无需临时变量或指针。

```go
a, b := 1, 2
a, b = b, a  // a=2, b=1
```

传参交换要用指针：`func swap(p, q *int)`。

### 再追问

`a, b := b, a` 能交换吗？——可以，`:=` 右侧先求值再赋值。

## Q12

**★★★★☆｜值班：同事 Go 工具本地 `go run .` 正常，CI `GOOS=linux go build` 报类型错误——你第一步做什么？**

**覆盖**：常用 | **对应**：知识点 [九、作战：读编译错误定责](知识点.md)

### 场景

Mac 开发、Linux 容器构建，怀疑 `int` 宽度或 build tag。

### 完整解答

> 🎯 **一句话**：**先读完整编译错误行号** → 本地同环境 `GOOS=linux GOARCH=amd64 go build` 复现 → 查类型转换与 build tag。

```bash
GOOS=linux GOARCH=amd64 go build -v ./...
```

若是 `int` vs `int64`，统一显式转换；若是文件平台专属，看 `//go:build`（02 章）。

> 📝 **面试**：「Go 交叉编译默认简单，多数是代码假设了类型宽度或未用 build tag。」

### 再追问

`int` 在 32 位和 64 位机宽度一样吗？——不一样，对外协议别用裸 `int` 存 ID。

## Q13

**★★★★★｜白板：口述「一个 Go 值的一生」主图。**

**覆盖**：核心 · 必会 | **对应**：知识点 [一、一张图：一个 Go 值的一生](知识点.md)

### 场景

面试最后一轮 Go 基础。

### 完整解答

> 🎯 **一句话**：声明 → 零值或初值 → 表达式使用（含显式转换）→ 传值/指针 → 作用域结束 → GC。

主图节点：`var/:=` → 零值分支 → 类型检查 → `T(v)` → 函数调用 → 回收。

**读图**：编译器在类型不匹配处拦住；运维 bug 多在导出字段与零值语义。

### 再追问

栈上 vs 堆上分配本章需要讲吗？——了解即可，逃逸分析见 11 章。

## Q14

**★★★★★｜读代码找 bug：**

```go
type Alert struct {
    level   string
    Message string
}

func main() {
    a := Alert{level: "critical", Message: "disk full"}
    b, _ := json.Marshal(a)
    fmt.Println(string(b))
}
```

**覆盖**：核心 · 必会 | **对应**：知识点 [七、结构体与导出规则](知识点.md)

### 场景

告警 JSON 只有 `Message`，severity 丢了。

### 完整解答

> 🎯 **一句话**：`level` **未导出**，JSON 编码跳过；应改为 `Level string \`json:"level"\``。

```json
{"Message":"disk full"}
```

修法：`Level` 大写 + tag；或自定义 `MarshalJSON`。

### 再追问

若 `level` 大写但没 tag，JSON 字段名是什么？——默认 `Level`（不是 `level`）。
