## Q1

**★★★★★｜`a = [1,2]; b = a; b.append(3)` 之后 `a` 是什么？为什么说 Python 变量不是「盒子」？**

**覆盖**：核心 · 必会 · 常考 | **对应**：知识点 [二、出生：名字、类型与身份](知识点.md)

### 场景

同事写主机分组脚本，把 `prod_hosts = base_hosts` 后往 `prod_hosts` 里加机器，结果 `base_hosts` 也被改了，预发环境多出一批生产 IP。

### 完整解答

> 🎯 **一句话**：`a` 仍是 `[1, 2, 3]`；赋值只是**多贴一张条**到同一 list，不是拷贝。

```python
a = [1, 2]
b = a
b.append(3)
print(a)        # [1, 2, 3]
print(a is b)   # True
```

修法：需要独立列表用 `b = list(a)` 或 `a.copy()`；嵌套结构用 `copy.deepcopy`（见 Q8）。

> 📝 **面试**：「Python 是引用语义；要隔离副本必须显式拷贝。」

### 再追问

`b = [1, 2]` 再 `b.append(3)` 会影响 `a` 吗？——不会，`b` 已绑定到新 list。

## Q2

**★★★★★｜`[] == []` 和 `[] is []` 分别是什么？什么时候必须用 `is`？**

**覆盖**：核心 · 必会 · 常考 | **对应**：知识点 [三、相等 == 与身份 is](知识点.md)

### 场景

Code Review 有人写 `if result == None:`，也有人写 `if not result:` 处理 API 返回，两者在「API 失败返回 None」和「扫描结果为空列表」时行为不同。

### 完整解答

> 🎯 **一句话**：`==` 为 True、`is` 为 False；**`None` 判断用 `is`**，内容比较用 `==`。

```python
[] == []    # True  内容相等
[] is []    # False 两次 [] 是两个对象

x = None
if x is None:    # 推荐
    pass
```

`if not result` 把 `None`、`[]`、`""` 都当假；要区分「失败未赋值」和「成功但为空」必须分步写。

> ⚠️ **别混**：不要用 `is` 比较字符串或列表内容；`is` 只用于身份（几乎就是 `None`）。

### 再追问

`a = 256; b = 256; a is b` 可能为 True（小整数缓存），能推广到所有整数吗？——不能，大整数可能 `is` 为 False，**永远用 `==` 比数值**。

## Q3

**★★★★☆｜下列在 `if x:` 里分别是真还是假？`0`、`""`、`[]`、`{}`、`"0"`、`[0]`**

**覆盖**：必会 · 常考 | **对应**：知识点 [四、真值：truthiness](知识点.md)

### 场景

告警脚本 `if error_count:` 才发飞书；某次磁盘满但 `error_count=0`（计数逻辑 bug），告警没发——真值与业务语义要对齐。

### 完整解答

> 🎯 **一句话**：假值只有 `None`、False、0、空容器、空串；**`"0"` 和 `[0]` 为真**。

| 表达式 | `bool(...)` |
|--------|-------------|
| `0` | False |
| `""` | False |
| `[]` | False |
| `{}` | False |
| `"0"` | True |
| `[0]` | True |

```python
error_count = 0
if error_count:
    send_alert()   # 不会执行 —— 0 是合法计数时要另写规则
```

### 再追问

`if pods:` 和 `if len(pods) > 0:` 等价吗？——对 list 通常等价；自定义类可能只实现 `__len__` 不实现 `__bool__`，运维标准库类型可视为等价。

## Q4

**★★★★☆｜函数默认 `hosts=None`，内部 `if hosts is None: hosts = []` 和直接 `if not hosts: return` 各解决什么问题？**

**覆盖**：必会 · 常用 | **对应**：知识点 [四、真值：truthiness](知识点.md)

### 场景

批量 SSH 扫描函数 `scan(hosts=None)`，调用方有时不传、有时传 `[]` 表示「明确不扫」。

### 完整解答

> 🎯 **一句话**：`is None` 区分「未传参」；`if not hosts` 表示「列表为空则跳过」。

```python
def scan(hosts=None):
    if hosts is None:
        hosts = load_from_inventory()
    if not hosts:
        return {"scanned": 0}
    ...
```

若业务上「传 `[]`」与「不传」语义不同，不要用 `hosts=[]` 作默认参数（见 03 章可变默认参数）。

> ⚠️ **别混**：`if not hosts` 无法区分 `None` 与 `[]`，除非你先处理了 `None`。

### 再追问

为什么默认参数不能写 `hosts=[]`？——可变默认参数只创建一次，多次调用共享同一 list（03 章 Q6）。

## Q5

**★★★★☆｜`prod = staging` 后改 `prod["replicas"]`，`staging` 会变吗？**

**覆盖**：核心 · 必会 | **对应**：知识点 [五、可变性：mutability](知识点.md)

### 场景

从 `staging` 配置 dict 复制出 `prod` 只改副本数，结果 staging 也被扩缩容。

### 完整解答

> 🎯 **一句话**：会变；dict 可变，**别名共享**。

```python
staging = {"replicas": 2, "labels": {"env": "stg"}}
prod = staging
prod["replicas"] = 10
print(staging["replicas"])   # 10
```

修法：`prod = copy.deepcopy(staging)` 或 `prod = {**staging, "replicas": 10}`（浅层键要懂是否嵌套）。

### 再追问

`prod = dict(staging)` 后改 `prod["labels"]["x"]=1` 会影响 staging 吗？——会，浅拷贝只复制顶层键，嵌套 dict 仍共享。

## Q6

**★★★★★｜`rows = get_metrics(); rows = rows.sort()` 之后 CI 报 `TypeError`，为什么？**

**覆盖**：核心 · 常考 | **对应**：知识点 [五、可变性：mutability](知识点.md)

### 场景

按 CPU 排序 Pod 指标后取前三，脚本在 `for r in rows` 崩溃。

### 完整解答

> 🎯 **一句话**：`list.sort()` **原地排序且返回 `None`**，不能把返回值赋回 `rows`。

```python
rows = [{"cpu": 0.3}, {"cpu": 0.9}]
rows.sort(key=lambda r: r["cpu"], reverse=True)   # 正确
top = sorted(rows, key=lambda r: r["cpu"], reverse=True)  # 需要新列表时
```

错误写法：

```python
rows = rows.sort()   # rows 变成 None
```

> 📝 **面试**：「原地方法 `sort`/`reverse` 返回 None；要链式用 `sorted()`。」

### 再追问

`sorted()` 会改原列表吗？——不会，返回新 list。

## Q7

**★★★★☆｜`s = "abcdef"`，`s[1:4]`、`s[:]`、`s[::-1]`、`s[4:1:-1]` 各是什么？**

**覆盖**：必会 · 常考 | **对应**：知识点 [六、切片：slice 语法与边界](知识点.md)

### 场景

从 `kubectl` 表格字符串取倒数第二列、反转版本号做比较。

### 完整解答

> 🎯 **一句话**：`bcd`、全串副本、`fedcba`、`edc`（含 start 不含 stop，步长可负）。

```python
s = "abcdef"
s[1:4]      # 'bcd'
s[:]        # 'abcdef' 新 str
s[::-1]     # 'fedcba'
s[4:1:-1]   # 'edc'
```

list 同理；`lines[1:]` 跳过表头。

### 再追问

`lst[10:20]` 在 `len(lst)==5` 时会报错吗？——不会，返回 `[]`。

## Q8

**★★★★☆｜什么时候 `list(a)` 够用，什么时候必须 `deepcopy`？**

**覆盖**：必会 · 常用 | **对应**：知识点 [五、可变性：mutability](知识点.md)

### 场景

多集群告警模板共享 `annotations` 嵌套 dict，改一个集群的 `annotations["runbook"]` 其他集群链接也变了。

### 完整解答

> 🎯 **一句话**：**只有一层可变容器**用浅拷；**嵌套可变**用 `deepcopy`。

```python
import copy
template = {"labels": {"team": "sre"}, "tags": ["oncall"]}
a = template.copy()
a["tags"].append("prod")   # template["tags"] 也变

b = copy.deepcopy(template)
b["tags"].append("stg")    # template 不变
```

### 再追问

`{**d}` 算深拷贝吗？——否，顶层新 dict，值仍是引用。

## Q9

**★★★☆☆｜`path = "/var/log"; path += "/app"` 会改原字符串吗？**

**覆盖**：必会 | **对应**：知识点 [五、可变性：mutability](知识点.md)

### 场景

循环里 `prefix += cluster` 拼路径，有人担心性能或「修改常量」。

### 完整解答

> 🎯 **一句话**：`str` 不可变，`+=` 绑定**新**字符串对象。

```python
path = "/var/log"
old_id = id(path)
path += "/app"
print(id(path) != old_id)   # True
```

大量拼接用 `"".join(parts)` 或 `io.StringIO`（大日志场景）。

### 再追问

`tuple` 里放 list，能改 list 吗？——能，`tuple` 不可变的是「槽位引用」，list 内容仍可 `append`。

## Q10

**★★★☆☆｜`t = ([1, 2], 3)`，`t[0].append(4)` 合法吗？`t[0] = [5]` 呢？**

**覆盖**：常考 | **对应**：知识点 [五、可变性：mutability](知识点.md)

### 场景

把 `(host_list, port)` 当缓存键，有人往 `host_list` 里加 IP 导致「键」语义变了。

### 完整解答

> 🎯 **一句话**：`append` 合法；**给 `t[0]` 重新赋值**会 `TypeError`。

```python
t = ([1, 2], 3)
t[0].append(4)   # OK, t == ([1, 2, 4], 3)
t[0] = [5]       # TypeError: 'tuple' object does not support item assignment
```

### 再追问

为何 dict 的 key 常用 tuple 不用 list？——key 须可哈希，list 不可哈希。

## Q11

**★★★★☆｜`kubectl get pods` 输出按行解析，为什么常用 `lines[1:]` 而不是 `lines[1]`？**

**覆盖**：常用 · 实操 | **对应**：知识点 [六、切片：slice 语法与边界](知识点.md)

### 场景

解析多行表格，第一行是 `NAME READY STATUS`，后面每行一个 Pod。

### 完整解答

> 🎯 **一句话**：`[1:]` 取**所有数据行**；`[1]` 只取**第二行**一个字符串。

```python
lines = ["NAME READY", "pod-a 1/1 Running", "pod-b 0/1 Pending"]
data = lines[1:]
# ['pod-a 1/1 Running', 'pod-b 0/1 Pending']
```

空输出时先 `if not lines: return []` 再切片。

### 再追问

如何跳过前两行？——`lines[2:]`。

## Q12

**★★★★☆｜脚本「排序后是 None、分支没进、两环境配置串了」——60 秒怎么查？**

**覆盖**：常用 · 实操 | **对应**：知识点 [八、作战](知识点.md)

### 场景

oncall 接手同事写的发布前检查脚本，三个现象同时出现。

### 完整解答

> 🎯 **一句话**：先 `type/repr/id`，再查 `sort` 返回值，再查 `a=b` 别名与拷贝深度。

| 时段 | 动作 |
|------|------|
| 0–10s | 异常行上方打印 `type(x), repr(x)` |
| 10–30s | 是否 `x = x.sort()` → 改 `sorted` 或分行 `sort` |
| 30–45s | `id(a)==id(b)` 是否共享引用 |
| 45–60s | 嵌套 dict 改 `deepcopy` |

```python
import pprint
pprint.pp({"t": type(x), "r": repr(x), "id": id(x)})
```

> ⚠️ **别混**：别在生产留调试打印含密钥；用 staging 复现。

### 再追问

`is` 能用来查别名吗？——可以 `a is b`，但不要用来比内容。

## Q13

**★★★★★｜白板：画出 Python 对象从创建到被 GC 的主路径，标出 truthiness 和 mutability 两站。**

**覆盖**：核心 · 常考 | **对应**：知识点 [一、一张图：一个 Python 对象的一生](知识点.md)

### 场景

面试最后一轮手写「Python 基础」。

### 完整解答

> 🎯 **一句话**：创建绑定 → `if`/真值 → 索引切片 → 可变则别名可见 / 不可变则新对象 → 引用计数 0 回收。

主图节点：字面量/构造 → 名字绑定 → 真值测试 → 索引/切片 → 可变分支（原地改）vs 不可变（新对象）→ GC。

**读图**：运维 bug 多在真值（空 vs None）和可变（共享引用）两站。

### 再追问

CPython 主要靠什么回收？——引用计数为主，循环引用由 `gc` 模块辅助（了解即可）。

## Q14

**★★★★★｜读代码找 bug：**

```python
DEFAULT = {"timeout": 30, "tags": []}

def opts_for(cluster):
    o = DEFAULT
    o["tags"].append(cluster)
    return o

print(opts_for("cn"))
print(opts_for("sg"))
```

**覆盖**：核心 · 必会 | **对应**：知识点 [五、可变性](知识点.md)、[七、收束](知识点.md)

### 场景

多集群请求选项「应该各自独立」，第二个集群却带着第一个的 tag。

### 完整解答

> 🎯 **一句话**：`o = DEFAULT` 共享同一 dict，且 **`tags` 列表跨调用累积**。

```python
# 第一次后 DEFAULT["tags"] == ["cn"]
# 第二次后 == ["cn", "sg"]
```

修法：

```python
import copy
def opts_for(cluster):
    o = copy.deepcopy(DEFAULT)
    o["tags"] = [cluster]
    return o
```

或每次 `{"timeout": 30, "tags": [cluster]}` 新建。

> 📝 **面试**：「模块级可变默认 + 别名 = 状态泄漏；函数内要拷贝或新建。」

### 再追问

若写成 `o = DEFAULT.copy()` 仍 `o["tags"].append(cluster)` 会怎样？——多个 `o` 仍共享同一 `tags` list（浅拷）。
