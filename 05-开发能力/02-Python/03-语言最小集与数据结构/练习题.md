## Q1

**★★★★★｜扫描 5000 台主机，判断 IP 是否在黑名单里，用 list 还是 set？为什么？**

**覆盖**：核心 · 必会 · 常考 | **对应**：知识点 [四、去重：set](知识点.md)

### 场景

活动前黑名单两千 IP，巡检脚本每台 `if ip in blacklist`，耗时从分钟涨到小时。

先自己试试：不看下面，你能口述答案吗？讲完再对「完整解答」。


### 完整解答

> 🎯 **一句话**：用 **set**；`in` 平均 O(1)，list 是 O(n)。

```python
BLACKLIST = frozenset(load_blacklist())  # 启动时一次

def blocked(ip: str) -> bool:
    return ip in BLACKLIST
```

报告输出若要稳定顺序：`for ip in sorted(blocked_ips):`。

> 📝 **面试**：「membership 大数据用 set；要顺序用 list 或 sorted。」

### 再追问

黑名单本身要保文件顺序展示？——存储用 list，**查询用 `set(blacklist)` 缓存**。

## Q2

**★★★★★｜下面代码第二次调用为什么多出一个 tag？怎么改？**

```python
def alert_meta(severity, tags=[]):
    tags.append(severity)
    return tags
```

**覆盖**：核心 · 必会 · 常考 | **对应**：知识点 [六、死亡陷阱：可变默认参数](知识点.md)

### 场景

告警模板函数第一次 `alert_meta("warning")` 正常，第二次带上次的 severity——这是 Q1 结论的加深版。

先自己试试：不看下面，你能口述答案吗？讲完再对「完整解答」。


### 完整解答

> 🎯 **一句话**：默认 `[]` **只创建一次**，调用间共享。

```python
def alert_meta(severity, tags=None):
    if tags is None:
        tags = []
    tags = list(tags)          # 若允许传入外部 list，防改调用方
    tags.append(severity)
    return tags
```

> ⚠️ **别混**：`tags=None` 与 `tags=[]` 语义完全不同。

### 再追问

`def f(cfg={})` 同样坑吗？——是，默认 dict 也共享。

## Q3

**★★★★☆｜`failed_hosts` 用 list 每次 `if h not in failed_hosts: failed_hosts.append(h)` 有什么问题？**

**覆盖**：必会 · 常用 | **对应**：知识点 [二、list](知识点.md)、[四、set](知识点.md)

### 场景

失败主机重复 append，去重循环变成 O(n²)。

先自己试试：不看下面，你能口述答案吗？讲完再对「完整解答」。


### 完整解答

> 🎯 **一句话**：**重复检查 O(n)**，总体 O(n²)；改用 **set add**。

```python
failed: set[str] = set()
for h in hosts:
    if not ok(h):
        failed.add(h)
return sorted(failed)
```

若既要 set 去重又要首次失败顺序，用 `dict.fromkeys`：

```python
ordered_unique = list(dict.fromkeys(failed_list))
```

### 再追问

`len(set(lst)) != len(lst)` 说明什么？——有重复元素。

## Q4

**★★★★☆｜`cache[(host, port)] = latency` 合法吗？`cache[[host, port]] = latency` 呢？**

**覆盖**：必会 · 常考 | **对应**：知识点 [三、映射：dict](知识点.md)

### 场景

用「主机+端口」当缓存键，有人用 list 拼键报 `unhashable`。

先自己试试：不看下面，你能口述答案吗？讲完再对「完整解答」。


### 完整解答

> 🎯 **一句话**：**tuple 可哈希可作键**；**list 不可**。

```python
cache: dict[tuple[str, int], float] = {}
cache[("10.0.0.1", 8080)] = 0.05

# cache[[host, port]] = 0.05  # TypeError
```

也可用 `f"{host}:{port}"` 字符串键，注意 IPv6 格式一致。

### 再追问

dict 里放 list 作**值**可以吗？——可以，只是键不能是 list。

## Q5

**★★★★☆｜统计日志里 ERROR/WARN/INFO 条数，用 Counter 怎么写？**

**覆盖**：常用 | **对应**：知识点 [三、dict — Counter](知识点.md)

### 场景

发版后拉 1 万行日志，要 Top 级别分布给 oncall 摘要。

先自己试试：不看下面，你能口述答案吗？讲完再对「完整解答」。


### 完整解答

> 🎯 **一句话**：`Counter(iterable)`，缺键返回 0，`most_common` 取 Top。

```python
from collections import Counter

levels = [parse_level(ln) for ln in lines]  # 或生成器
c = Counter(levels)
print(c.most_common(3))
# [('ERROR', 120), ('WARN', 45), ('INFO', 9835)]
```

### 再追问

两个 Counter 能相加吗？——可以，`c1 + c2` 合并计数。

## Q6

**★★★☆☆｜什么时候用列表推导，什么时候必须用 for？**

**覆盖**：必会 | **对应**：知识点 [七、遍历与推导](知识点.md)

### 场景

Review 里有人写 `[send_alert(h) for h in failed]` 或三层嵌套推导。

先自己试试：不看下面，你能口述答案吗？讲完再对「完整解答」。


### 完整解答

> 🎯 **一句话**：**纯变换/过滤用推导**；**有副作用（IO、日志、写文件）用 for**。

```python
# 好
ready = [p for p in pods if is_ready(p)]

# 差
# [send_alert(h) for h in failed]

for h in failed:
    send_alert(h)
```

嵌套超过两层优先 for，可读性第一。

### 再追问

推导比 for 一定更快吗？——常略快，但运维脚本瓶颈多在网络 IO。

## Q7

**★★★☆☆｜`zip(hosts, ports)` 长度不一致会怎样？`enumerate(lines, start=1)` 解决什么？**

**覆盖**：常用 | **对应**：知识点 [七、遍历与推导](知识点.md)

### 场景

并行扫主机和端口，两列表长度不同导致静默丢数据。

先自己试试：不看下面，你能口述答案吗？讲完再对「完整解答」。


### 完整解答

> 🎯 **一句话**：`zip` **截断到最短**；要对齐先 `len` 检查。`enumerate` 给**行号**从 1 起便于报障。

```python
if len(hosts) != len(ports):
    raise ValueError("hosts/ports length mismatch")

for i, line in enumerate(log_lines, start=1):
    if "FATAL" in line:
        print(f"line {i}: {line}")
```

Python 3.10+ 可用 `zip(hosts, ports, strict=True)` 长度不等直接抛错。

### 再追问

`zip(*rows)` 做什么？——转置表格行列为列行（解析 TSV 时用）。

## Q8

**★★★★☆｜去重但保持首次出现顺序，一行怎么写？**

**覆盖**：常考 | **对应**：知识点 [四、set](知识点.md)

### 场景

API 返回重复 Pod 名，报告里要按首次见到顺序列唯一名。

先自己试试：不看下面，你能口述答案吗？讲完再对「完整解答」。


### 完整解答

> 🎯 **一句话**：`list(dict.fromkeys(names))`（3.7+ 保序）。

```python
names = ["a", "b", "a", "c"]
unique_ordered = list(dict.fromkeys(names))
# ['a', 'b', 'c']
```

### 再追问

和 `sorted(set(names))` 区别？——后者按字典序，不是首次顺序。

## Q9

**★★★☆☆｜遍历 list 时 `remove` 元素为什么会漏删？**

**覆盖**：常用 | **对应**：知识点 [二、list](知识点.md)

### 场景

清理 `hosts` 里 down 的机器，边遍历边 `remove` 漏了一半。

先自己试试：不看下面，你能口述答案吗？讲完再对「完整解答」。


### 完整解答

> 🎯 **一句话**：删除会**缩短列表、前移索引**，迭代器跳过下一项。

```python
# 错
for h in hosts:
    if down(h):
        hosts.remove(h)

# 对：新列表
hosts = [h for h in hosts if not down(h)]
```

### 再追问

要原地改？——`hosts[:] = [h for h in hosts if not down(h)]`。

## Q10

**★★★★☆｜访问 `pod["metadata"]["name"]` 怕 KeyError，推荐写法？**

**覆盖**：必会 · 常用 | **对应**：知识点 [三、dict](知识点.md)

### 场景

K8s API 返回缺字段的 CRD，脚本直接索引崩溃。

先自己试试：不看下面，你能口述答案吗？讲完再对「完整解答」。


### 完整解答

> 🎯 **一句话**：**.get 链**或先 `isinstance` 校验结构。

```python
name = (
    pod.get("metadata") or {}
).get("name", "unknown")

# 或 3.11+ 可读性
meta = pod.get("metadata")
name = meta.get("name", "unknown") if isinstance(meta, dict) else "unknown"
```

严重结构错误应抛自定义异常（04 章），不要静默吞掉所有错误。

### 再追问

`pod["metadata"]["name"]` 与 `.get` 何时用硬索引？——内部协议确定字段必有时。

## Q11

**★★★☆☆｜黑名单为什么用 `frozenset` 而不是 `set`？**

**覆盖**：常考 | **对应**：知识点 [生产模板 4](知识点.md)

### 场景

常量黑名单被某函数误 `add`，全局生效。

先自己试试：不看下面，你能口述答案吗？讲完再对「完整解答」。


### 完整解答

> 🎯 **一句话**：**frozenset 不可变**，共享时不会被意外修改；仍支持 `in`。

```python
BLACKLIST: frozenset[str] = frozenset({"10.0.0.1"})
# BLACKLIST.add("x")  # AttributeError
```

运行时构建的黑名单用普通 `set` 即可。

### 再追问

frozenset 能作 dict 键吗？——能，可哈希。

## Q12

**★★★★☆｜脚本第二次运行结果「带着第一次的脏 tags」，60 秒查什么？**

**覆盖**：实操 | **对应**：知识点 [九、作战](知识点.md)

### 场景

同一 Python 进程里连续调两次检查函数（REPL 或长驻 worker），第二次 labels 异常。

先自己试试：不看下面，你能口述答案吗？讲完再对「完整解答」。


### 完整解答

> 🎯 **一句话**：查 **可变默认参数**、**模块级可变常量**、**别名未拷贝**。

```python
import inspect
print(inspect.signature(suspect_func))  # 默认有没有 []
```

进程内复现：同一 interpreter 下连调两次；若每次新进程则查是否写文件/读缓存。

### 再追问

单元测试间状态泄漏？——`tearDown` 清模块级 CACHE 或 pytest fixture 隔离。

## Q13

**★★★★★｜白板：主机扫描结果要「每台状态 dict + 失败主机有序列表」，画出用什么结构、怎么填。**

**覆盖**：核心 · 常考 | **对应**：知识点 [一、一张图](知识点.md)、[八、收束](知识点.md)

### 场景

面试手写数据流——这张题把前面十道题串起来了。

先自己试试：不看下面，你能口述答案吗？讲完再对「完整解答」。


### 完整解答

> 🎯 **一句话**：`status: dict[str,str]` 填每台；`failed: set` 收集失败；返回前 `sorted(failed)`。

```python
status = {}
failed = set()
for h in hosts:
    ok = check(h)
    status[h] = "up" if ok else "down"
    if not ok:
        failed.add(h)
return status, sorted(failed)
```

### 再追问

失败还要保留首次顺序？——用 `list(dict.fromkeys(...))` 在扫描时记录。

## Q14

**★★★★★｜读代码找问题：**

```python
DEFAULT_LABELS = {"env": "prod", "tags": []}

def labels_for(cluster, extra_tags=None):
    lb = DEFAULT_LABELS
    lb["cluster"] = cluster
    if extra_tags:
        lb["tags"].extend(extra_tags)
    return lb
```

**覆盖**：核心 · 必会 | **对应**：知识点 [六、可变默认](知识点.md)、[八、收束](知识点.md)

### 场景

`labels_for("cn", ["a"])` 后 `labels_for("sg")` 的 tags 里仍有 `a`。

先自己试试：不看下面，你能口述答案吗？讲完再对「完整解答」。


### 完整解答

> 🎯 **一句话**：**共享 DEFAULT_LABELS**，且嵌套 **tags list 跨调用累积**。

修法：

```python
import copy

def labels_for(cluster, extra_tags=None):
    lb = copy.deepcopy(DEFAULT_LABELS)
    lb["cluster"] = cluster
    if extra_tags:
        lb["tags"] = list(extra_tags)
    return lb
```

或每次 `{"env": "prod", "tags": list(extra_tags or [])}` 新建。

> 📝 **面试**：「模块级可变 + 别名赋值 = 状态泄漏；返回前要拷贝或新建。」

### 再追问

若 `lb = DEFAULT_LABELS.copy()` 够吗？——不够，`tags` 仍共享。
