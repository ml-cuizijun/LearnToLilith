# 03｜变量引号与参数展开 · SRE 开发能力

> 大家好，欢迎来到这次分享。开讲之前，先带大家回到一个活动前批量改配置的现场：
> 有人写 `for i in $hosts` 把三台机器打成一条 SSH；有人 `rm -rf $dir/*` 在 `dir` 为空时删了根目录——群里已经有人在问「能不能从备份回滚」。
> 这一章讲完，你会知道当时那两个人各自错在哪——根因往往不是「不会写循环」，而是**字符串从赋值到展开**的路上丢了引号、没设默认值、或 glob 在空变量时暴走。
> **本章回答的问题**：一个 Shell 字符串从 `=` 赋值、经引号保护、到 `${}` 展开、word splitting、glob，最后变成命令参数的全过程——哪一步会炸、生产怎么写才稳。
> **本章不讲**：三开关 `set -euo pipefail` → [02 脚本骨架](../02-脚本骨架与三开关/)；管道与 `PIPESTATUS` → [06](../06-管道重定向与PIPESTATUS/)；正则提取字段 → [04 正则](../../04-正则与文本处理/)。

**怎么听这场分享**：先把「一个字符串从赋值到展开」主图装进脑子——赋值 → 引号 → `${}` → splitting → glob；后面每一节都是这张图上的一段；原理讲透三节专门放慢；生产模板可直接复制。每一节讲完会提示对应练习题，趁热打铁。

## 面试怎么考

| 标记 | 考点 |
|------|------|
| **核心** | 展开顺序；单引号 vs 双引号；`"$var"` 防 splitting；`${var:-}` 默认值 |
| **必会** | `IFS` 与 word splitting；空变量 + glob 删根；`${var#*/}` 路径裁剪 |
| **常用** | `${var:?}` 缺参即退；`${var//old/new}` 批量替换；`"$@"` vs `$*` |
| **常考** | 不加引号 `*` 匹配当前目录；`$(( ))` vs `` ` ``；赋值 `=` 两侧不能有空格 |

**30 秒怎么说**：Shell 字符串先赋值再经七步展开。生产变量**一律双引号** `"$var"`，只有故意要 splitting 或 glob 时才放开。默认值用 `${var:-default}`，缺参致命用 `${var:?msg}`。`for f in $files` 在空变量时会变成 `for f in *`——要么 `"$@"` 传数组，要么先 `[[ -n "$files" ]]`。路径裁剪 `${path##*/}` 取 basename，别手写 `sed` 切。

## 能力边界

| 维度 | 变量/引号/展开 | Python str | Go string |
|------|----------------|------------|-----------|
| **适合** | 跳板机脚本、kubectl 包装、批量 SSH 参数 | 结构化日志、API 响应解析 | 常驻工具、并发 worker |
| **不适合** | 复杂嵌套数据结构（用数组或换语言） | 一行 shell 里嵌十层 `${}` | 快速改三台机配置 |
| **生命周期** | Runbook 脚本、CI 一步 | 可入库、单测 | 二进制分发 |
| **vs 彼此** | 最快写、最易引号炸 | `os.environ` 稳 | `flag` 包稳 |

三个角色不要混：

| 角色 | 干什么 | 面试口径 |
|------|--------|----------|
| **双引号** | 保留字面空格、阻止 splitting/glob，仍展开 `$` | **默认选择** |
| **单引号** | 完全字面量，不展开 | 包 `awk '{print $1}'` |
| **不加引号** | 主动 splitting + glob | 仅 `case` 模式或刻意 `*` |

> **记住**：review Shell 脚本第一眼看引号——凡 `$` 变量在命令参数位置，没双引号就标红。

好，边界清楚了。先上主图——字符串从 `=` 到 `argv[]`，中间哪几步会炸。

## 一、一张图：一个字符串从赋值到展开的一生

> 🎯 **一句话**：`name=value` 存进内存 → 引号决定哪些字符参与展开 → 七步展开把字符串切成词 → 最后交给 `execve` 当 `argv[]`。

```mermaid
flowchart LR
    A["赋值 name=value"] --> B["引号层<br/>' 字面 / \" 半展开"]
    B --> C["大括号 ${}<br/>默认值/裁剪"]
    C --> D["命令 $( )<br/>算术 $(( ))"]
    D --> E["Word Splitting<br/>IFS 切词"]
    E --> F["Pathname Glob<br/>* ? []"]
    F --> G["引号摘除<br/>→ argv[]"]

    H["⚠️ 炸点"] --> E
    H --> F
```

**读图**：咱们先把这张图当地图——从左到右是 Bash 对**未加引号**片段的处理顺序（简化版）。`"$var"` 在引号摘除前**跳过** splitting 和 glob——所以 `"$hosts"` 三台机器仍是一个参数，而 `$hosts` 会变成三个。glob 在 splitting 之后：空变量 `cmd $dir/*` 可能变成 `cmd /*`。监控脚本里「偶发删错目录」多半出在第 ⑤⑥ 步。

好，主图装进脑子了。从「出生」开始——赋值这一步看起来简单，笔试却最爱考空格。

本节对应练习题 Q1、Q14。

## 二、出生：赋值与名字

> 🎯 **一句话**：`=` 两侧**不能有空格**；`declare`/`local`/`readonly` 带属性；环境变量 `export` 才进子进程。

```bash
# 正确
name="game-server-01"
count=3
readonly DEPLOY_ENV="prod"

# 经典笔试坑：空格把 name 当命令
name = "foo"    # ← bash: command not found: name

# 命令替换赋值——先跑命令，结果当字符串
ts=$(date +%Y%m%d)
ip=$(hostname -I | awk '{print $1}')
```

> ⚠️ **别混**：`name=value command` 是**仅对该命令**临时设环境变量，不等于 `name=value` 后再跑 `command`。`export VAR` 才被子进程继承；普通赋值子 shell 看不到。

> 🔍 **现场**：脚本里读配置常混两种来源——

```bash
# 文件里 source
# deploy.conf: REPLICAS=3
source ./deploy.conf
echo "replicas=${REPLICAS:-1}"   # 文件没写则用 1

# 环境变量（K8s downward API / CI 注入）
echo "namespace=${NAMESPACE:?must set NAMESPACE}"
```

**读图**：赋值只决定「内存里有什么」；还没决定「交给命令时长什么样」——那是后面引号和展开的事。

赋值定了，接下来是全章最重要的一层：**引号**。口诀先埋一句——**生产默认双引号**。

本节对应练习题 Q12。

## 三、引号：字面量 vs 可展开

> 🎯 **一句话**：单引号里**一切字面**；双引号里 `$`、`` ` ``、`\`、`!`（history）仍展开；不加引号触发 splitting 和 glob。

### 3.1 单引号 `'...'`

```bash
msg='root is $HOME, today is $(date)'   # 原样输出，不展开
awk_script='{print $1, $9}'             # awk 的 $1 不会被 shell 吃掉

grep -E 'error+' app.log                # + 在单引号里安全
```

> 💡 **打个比方**：单引号是「冷冻舱」——进去什么出来什么，Shell 不碰里面。

### 3.2 双引号 `"..."`

```bash
user="ops"
echo "hello $user"           # hello ops
echo "path=$HOME/bin"        # path=/root/bin
echo "today $(date +%F)"     # 命令替换仍执行

# 生产必写：防空格、防空、防 glob
ssh "$target_host" "systemctl restart $svc"
```

> ⚠️ **别混**：双引号**不**阻止 word splitting 发生在「引号外」的变量上——`"$a $b"` 是一个参数（中间有空格但整段是一个词）；`$a $b` 是两个参数。`"$@"` 是每个位置参数各一个引号包裹，**必用**；`"$*"` 会把所有参数合成**一个**字符串。

### 3.3 不加引号：何时故意放开

```bash
# 刻意 glob：删 7 天前日志
find /var/log/app -name '*.log' -mtime +7 -delete

# 刻意 splitting（老脚本常见，新脚本优先数组）
# files="a.log b.log c.log"
# for f in $files; do ...   # ← 有空格的文件名会炸，见下文踩坑

# case 分支模式（右边是模式不是命令参数）
case "$status" in
  200|201|204) echo ok ;;
  5*) echo 5xx ;;
esac
```

> 📝 **面试**：「生产默认双引号；单引号包 awk/sed 里带 `$` 的片段；不加引号只在明确要 glob 或 case 模式。」

引号层过了，`${}` 是给变量「加后缀操作」的地方——默认值四兄弟和路径裁剪，SRE 脚本天天写。

本节对应练习题 Q2、Q3。

## 四、参数展开：${} 全家桶

> 🎯 **一句话**：`${var}` 与 `$var` 等价，但 `{}` 能接后缀操作符；**默认值四兄弟** `:-` `:=` `:+` `:?` 和**裁剪** `#` `%` 是 SRE 脚本最常写的。

### 4.1 默认值与必填 ⭐

⭐ 这是面试必考。大家先别背表——想清楚：`set -u` 能抓「未定义」，抓不住「已定义但空串」；空串要靠 `:?` 或 `:-`。

| 写法 | var 未设或空 | var 有值 | 副作用 |
|------|-------------|---------|--------|
| `${var:-default}` | 用 default | 用 var | 无 |
| `${var:=default}` | 赋 default 给 var | 用 var | **会赋值** |
| `${var:+alt}` | 空 | 用 alt | 无 |
| `${var:?msg}` | **报错退出** | 用 var | 无 |

```bash
# 端口默认 8080，不污染原变量
port=${PORT:-8080}
curl -s "http://127.0.0.1:${port}/health"

# 缺参立刻失败——比跑到一半 ssh 连错机器强
host=${1:?usage: $0 <host>}
ssh "$host" 'uptime'

# 仅当设置了 DEBUG 才打开 -x
${DEBUG:+set -x}    # DEBUG 非空则展开为 set -x
```

> 🔍 **现场**：CI 里批量重启：

```bash
#!/usr/bin/env bash
NS=${NAMESPACE:?set NAMESPACE}
DEPLOY=${DEPLOYMENT:?set DEPLOYMENT}
kubectl rollout restart "deployment/${DEPLOY}" -n "$NS"
```

### 4.2 前缀/后缀裁剪 🔧

```bash
path="/var/log/nginx/access.log"
echo "${path##*/}"      # access.log  （最长后缀匹配 ##）
echo "${path%/*}"       # /var/log/nginx
echo "${path#*/}"       # var/log/nginx/access.log  （最短前缀 #）

# 去域名后缀
host="game-server-03.prod.example.com"
echo "${host%%.*}"      # game-server-03  （%% 最长前缀）
echo "${host#*.}"       # prod.example.com

# 批量替换
echo "${image//:/ }"    # 把冒号变空格——慎用，镜像 tag 里可能有 port
ver="${tag%-*}"         # v1.2.3-rc1 → v1.2.3
```

> 📝 **面试**：「`${var#pattern}` 最短前缀删，`##` 最长；`%` 后缀同理。取 basename 用 `${p##*/}`，比 `basename` 少一次 fork。」

口诀：**`#` 砍头、`%` 砍尾，写两遍是最长匹配**。

### 4.3 长度与切片

```bash
s="abcdefghij"
echo "${#s}"        # 10
echo "${s:2:4}"     # cdef  从索引 2 取 4 个
echo "${s: -3}"     # hij   最后 3 个（注意空格）
```

## 五、Word Splitting：一个词怎么变成很多个

> 🎯 **一句话**：展开后，Shell 按 **`IFS` 默认空格/制表/换行** 把字符串切成多个词，再分别当参数；**双引号包住整段可跳过此步**。

🔥 大白话：splitting 就是「按空格切香肠」。开头那个 `ssh $hosts` 把三台打成一条，根因就在这儿。

```bash
hosts="10.0.0.1 10.0.0.2 10.0.0.3"

# 三个参数 → ssh 只连第一台（或行为诡异）
# ssh $hosts uptime

# 一个参数「10.0.0.1 10.0.0.2 ...」→ ssh 报错
# ssh "$hosts" uptime

# 正确：循环或数组
for h in $hosts; do    # 这里故意 splitting：三台分开
  ssh "$h" uptime
done
```

> 💡 **打个比方**：word splitting 像用菜刀按空格切香肠——`"$sausage"` 是整根下锅，`$sausage` 会先切成片。

> ⚠️ **别混**：`IFS` 只影响 splitting，**不影响**引号内的字面空格。临时改 IFS 解析 CSV 是老写法，复杂表用 Python；若必须用：

```bash
line="10.0.0.1,game-srv-01,running"
IFS=',' read -r ip name st <<< "$line"
echo "$ip $name"
```

> 🔍 **现场**：`$*` vs `$@` 传参给函数——口诀：**`"$@"` 一人一份，`"$*"` 糊成一坨**：

```bash
run() { echo "argc=$#"; printf '<%s>\n' "$@"; }
run "a b" c
# argc=2
# <a b>
# <c>

run2() { printf '<%s>\n' "$*"; }
run2 "a b" c
# <a b c>    ← 合成一个
```

## 六、Pathname Expansion：glob 何时帮倒忙

> 🎯 **一句话**：未加引号的 `*`、`?`、`[...]` 由 Shell 展开成**匹配到的路径列表**；无匹配时字面保留（`nullglob` 关时）或为空（`failglob`）。

```bash
ls *.log                    # 当前目录所有 .log
rm -f /tmp/cache/*          # 正常

dir=""                      # 或 dir 未赋值
# rm -rf $dir/*             # ← 灾难：变成 rm -rf /* 
# 修法：
rm -rf "${dir:?dir empty}/"*
# 或
[[ -n "$dir" && -d "$dir" ]] && rm -rf "$dir"/*
```

> ⚠️ **别混**：`*.txt` 是 **Shell glob**，由路径展开阶段处理；`grep '*.txt'` 里的 `*` 是 **grep 的正则/BRE**（若不用 `-E` 甚至不是正则星号）——两层别混。见 [04 正则](../../04-正则与文本处理/)。

```bash
# 安全列文件
shopt -s nullglob
files=(/var/log/app/*.log)
(( ${#files[@]} == 0 )) && { echo "no logs"; exit 0; }
```

> 📝 **面试**：「空变量加 glob 是删根经典坑；`set -u` 能抓未定义变量，但空字符串仍过；用 `${var:?}` 或先判目录。」

口诀再钉一句：**空变量 + `*` = 删根；防线是 `${var:?}` + 先判目录**。好，把七步顺序串起来背。

本节对应练习题 Q1、Q8。

## 七、展开顺序：七步口诀 🔥

> 🎯 **一句话**：brace → tilde → parameter → command → arithmetic → splitting → pathname → quote removal（括号/算术在 splitting 前算完）。

🔥 这一节是全章最难背的一段——带着读者推：为什么 `"$var"` 能挡 splitting 和 glob，却挡不住 `$()` 执行？看完表你就有答案。

```bash
# 命令替换 $( ) 与反引号
echo "disk=$(df -h / | awk 'NR==2{print $5}')"

# 算术 $(( ))  —— 整型
i=0; ((i++)); echo $((i * 2))

# 嵌套：先算 $( )，再 splitting
files=$(ls *.conf 2>/dev/null)
# 若只有一个 .conf，$files 无引号时仍是一个词；多个则变多词
```

**现场走一遍**（debug 「参数从哪来」）：

```bash
set -x
target="10.0.0.1 10.0.0.2"
echo ssh $target uptime
# 展开后相当于：ssh 10.0.0.1 10.0.0.2 uptime → ssh 只吃第一个主机名

set +x
```

| 阶段 | 示例 | 双引号能挡？ |
|------|------|:------------:|
| Parameter | `$HOME`, `${port:-8080}` | 内层仍展开 |
| Command | `$(date)` | 会执行 |
| Arithmetic | `$((1+1))` | 会计算 |
| Splitting | `$hosts` | **能挡** `"$hosts"` |
| Pathname | `*.log` | **能挡** `"*.log"` 变字面星号 |
| Quote removal | 最后去掉引号壳 | — |

## 八、数组：多值别用空格字符串硬扛

> 🎯 **一句话**：`hosts=(a b c)` + `"${hosts[@]}"` 才是多值正道；字符串 `hosts="a b c"` 只是妥协。

```bash
hosts=(10.0.0.1 10.0.0.2 10.0.0.3)

# 展开每个元素，各是一个词
printf '<%s>\n' "${hosts[@]}"

# 错误：把数组当单个字符串
# ssh "${hosts[@]}"  # 仍只应循环

for h in "${hosts[@]}"; do
  ssh "$h" 'hostname'
done

# 从命令输出填数组
mapfile -t pods < <(kubectl get pods -n game -o jsonpath='{.items[*].metadata.name}')
echo "count=${#pods[@]}"
```

> 🔍 **现场**：批量滚动重启——这就是 Q7 那位同学该用的写法：

```bash
mapfile -t deploys < <(kubectl get deploy -n "$NS" -o name)
for d in "${deploys[@]}"; do
  kubectl rollout restart "$d" -n "$NS"
done
```

## 原理讲透

### 8.1 为什么 `"$var"` 是生产铁律

**一句话**：未引用的展开结果会再经历 splitting 和 glob——空格、空串、`*` 都会在**命令行解析层**改语义，而不是在变量里。

大家想想：变量里明明是空串，为什么 `rm` 会删到根？——错不在 `rm`，在展开层。

**打个比方**：变量是快递单上的地址；引号是「整单派送，禁止拆包」。拆开就可能把一栋楼拆成三个门牌号送给三个骑手。

**现场走一遍**（删缓存脚本删了根）：

1. `CACHE_DIR=` 配置漏了，变量空。
2. `rm -rf $CACHE_DIR/*` → 展开为 `rm -rf /*`。
3. 跳板机告警磁盘异常——实际是根分区文件被清。

**面试怎么说**：「所有 `$` 参数位置默认加双引号；例外是故意 splitting 的 `for i in $list` 或 `*.ext` glob。空变量配合 `*` 是删根高发区。」

### 8.2 `${var:-}` 与 `set -u` 分工

| 机制 | 抓什么 | 不抓什么 |
|------|--------|----------|
| `set -u` | **未定义**的变量 | 已定义为空串 `""` |
| `${var:?}` | 未定义 **或** 空 | — |
| `${var:-d}` | 提供默认值 | 不报错 |

```bash
set -u
empty=""
echo "${empty:-default}"   # default —— empty 已定义
# echo "$unset"            # unset: unbound variable
```

### 8.3 单引号里不能嵌套单引号

```bash
# 错误：awk '{print $1}'
# 正确：
awk '{print $1}' access.log
# 或拼接：
part1='{print '; part2='$1}'; awk "$part1$part2" access.log
# 生产更常：awk -v 传变量
```

## 生产模板

### 模板 1：带默认值的配置块

```bash
#!/usr/bin/env bash
set -euo pipefail

NS=${NAMESPACE:-game}
PORT=${PORT:-8080}
TIMEOUT=${CURL_TIMEOUT:-5}
API="http://127.0.0.1:${PORT}/health"

code=$(curl -s -o /dev/null -w '%{http_code}' --max-time "$TIMEOUT" "$API" || echo "000")
echo "health=$code ns=$NS"
```

### 模板 2：批量 SSH（引号 + 远程单引号）

```bash
#!/usr/bin/env bash
hosts=(10.0.0.11 10.0.0.12 10.0.0.13)
```

### 模板 3：安全清理目录

```bash
#!/usr/bin/env bash
set -euo pipefail

CACHE_DIR=${1:?usage: $0 <cache_dir>}
[[ -d "$CACHE_DIR" ]] || { echo "not a dir: $CACHE_DIR" >&2; exit 1; }
[[ "$CACHE_DIR" == /* ]] || { echo "must be absolute" >&2; exit 1; }

shopt -s nullglob dotglob
files=("$CACHE_DIR"/*)
if (( ${#files[@]} == 0 )); then
  echo "nothing to clean in $CACHE_DIR"
  exit 0
fi
rm -rf "${files[@]}"
echo "cleaned ${#files[@]} entries under $CACHE_DIR"
```

## 踩坑清单

| 现象 | 原因 | 修法 |
|------|------|------|
| `rm -rf /*` | `dir` 空 + `$dir/*` glob | `"${dir:?}"` + 判目录 |
| SSH 只连第一台 | `ssh $hosts` splitting | `for h; do ssh "$h"` |
| 文件名含空格断成两段 | `for f in $files` | 数组 + `"${arr[@]}"` |
| 脚本「变量明明有值」却空 | `source` 了带 Windows `^M` 的文件 | `dos2unix` |
| `[$var]` 语法错 | `[` 是命令，两侧要有空格 | `[[ $var == foo ]]` 或 `[ "$var" = foo ]` |
| awk `$1` 被 shell 吃掉 | 双引号包 awk 脚本 | 单引号包 `{print $1}` |
| `"*.log"` 不展开 | 引号阻止 glob | 故意则对；要 glob 别引号 |
| 默认值没生效 | 写成 `${var-}` 少冒号 | `${var:-default}` |
| `$*` 传参全糊一个 | `"$*"` 合成一串 | 用 `"$@"` |
| `local var=$(cmd)` 丢了退出码 | `local` 本身是命令，`$?` 变成 `local` 的码 | 先 `var=$(cmd)` 再 `local var=$var` 或单独 `local var` |
| `${arr[@]}` 加不加引号一样 | 不加引号会 splitting | `"${arr[@]}"` 每元素独立一个词 |
| `echo $var` 输出带换行变空格 | 不加引号触发 splitting | `echo "$var"` 保留换行 |

## 必会 · 常考

| 说法 | 对错 | 口径 |
|------|:----:|------|
| 赋值 `=` 两侧可以有空格 | 错 | 有空格是运行 `name` 命令 |
| 单引号里能写 `$HOME` | 对 | 但是**字面** `$HOME` |
| 双引号阻止变量展开 | 错 | 双引号**允许** `$` 展开 |
| `${var}` 和 `$var` 完全一样 | 错 | `{}` 才能接 `:-` `#` 等 |
| 空变量时 `*` 匹配当前目录所有文件 | 对 | 所以 `rm $d/*` 危险 |
| `set -u` 能防止空串 glob | 错 | 只防未定义，不防 `""` |
| `"$@"` 和 `"$*"` 一样 | 错 | `$@` 每个参数独立 |
| word splitting 按逗号切 | 错 | 默认 IFS 空格/Tab/换行 |
| `local var=$(cmd)` 后 `$?` 是命令的退出码 | 错 | `local` 本身是命令，覆盖退出码 |
| `${var-default}` 等于 `${var:-default}` | 错 | 少冒号时空串不触发默认值 |
| 数组 `${arr[*]}` 加不加引号一样 | 错 | 不加引号会 splitting |

**数字**：`${var:0:5}` 切片从 0 起 5 字符；`"${#var}"` 长度。`nullglob` 无匹配变空列表。

**易混**：splitting vs glob；`:-` vs `=` vs `:?`；单引号 vs 双引号；`$*` vs `$@`；Shell glob vs grep 正则。

**易错一句话对照**：

- 错：赋值 `name = value` → 对：`name=value` 两侧不能有空格
- 错：`local var=$(cmd)` 后直接看 `$?` → 对：`local` 会覆盖退出码，先赋值再 local
- 错：`echo $var` 带 `-n` / `*` 会被解析 → 对：`echo "$var"` 加引号
- 错：`${var-default}` 和 `${var:-default}` 一样 → 对：少冒号时「已定义但空」不触发默认值
- 错：`for f in $files` 文件名有空格也安全 → 对：不加引号会 splitting，用数组 + `"${arr[@]}"`
