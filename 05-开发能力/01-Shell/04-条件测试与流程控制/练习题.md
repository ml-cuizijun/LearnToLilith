## Q1

**★★★★★｜bash 脚本为什么优先 `[[ ]]` 而不是 `[ ]`？什么时候必须用 `[ ]`？**

**覆盖**：核心 · 必会 · 常考 ｜ **对应**：知识点 [二、出生：test 与 `[ ]` ⭐](知识点.md) · [三、进化：`[[ ]]` —— bash 内置、生产首选 ⭐](知识点.md)

### 场景

Code review：新人脚本里大量 `[ $x = y ]`，本地偶发 `unary operator expected`。——就是开头那个空变量炸 `[` 的现场；Q2 会从 `[[` 选型再挖一次。

先自己试试：不看下面，你能口述答案吗？讲完再对「完整解答」。


### 完整解答

> 🎯 **一句话**：`[[ ]]` 是 shell 关键字——不拆词、支持 `&&`/模式/正则；`[` 是 POSIX 外部命令，变量必须引号。

| 能力 | `[ ]` | `[[ ]]` |
|------|:-----:|:-------:|
| 变量未引号 splitting | 会 | 不会 |
| `&&` `\|\|` 内嵌 | 不行 | 可以 |
| `== *.log` 模式 | 不行 | 可以 |
| POSIX sh | 是 | 否 |

必须用 `[ ]`：目标 `/bin/sh` 严格 POSIX、极简容器只有 dash。bash 脚本默认 `[[ ]]`。

### 再追问

- `[[` 里 `=` 和 `==`？——bash 里字符串比较两者都可；`[ ]` 用 `=`。

## Q2

**★★★★★｜`[ $status = 200 ]` 在 status 为空时报什么错？写三种安全写法。**

**覆盖**：核心 · 必会 · 常考 ｜ **对应**：知识点 [二、出生：test 与 `[ ]` ⭐](知识点.md) · [原理讲透](知识点.md)

### 场景

监控脚本读 HTTP 码，配置漏了 `status` 变量，cron 邮件刷 `unary operator expected`。

先自己试试：不看下面，你能口述答案吗？讲完再对「完整解答」。


### 完整解答

> 🎯 **一句话**：`[` 看到 `[ = 200 ]` argv 不完整 → 语法错误，不是「条件为假」。

```bash
[[ $status == 200 ]]           # ← bash 首选
[ "$status" = "200" ]          # ← POSIX 安全
[[ -n "$status" && $status == 200 ]]  # ← 先判非空再比
```

加 `${status:?}` 在更早阶段失败也行。

### 再追问

- 为什么 `[[` 空变量不炸？——由当前 shell 解析，不是外部 `test` 命令拆 argv。

## Q3

**★★★★★｜为什么 `[[ "9" -gt "10" ]]` 和 `(( 9 > 10 ))` 结果不同？线上怎么写连接数阈值？**

**覆盖**：核心 · 必会 · 常考 ｜ **对应**：知识点 [四、三类测试：数值 · 字符串 · 文件 ⭐](知识点.md) · [原理讲透](知识点.md)

### 场景

脚本判断 `conn_count` 是否超过 1000，有人从日志读出 `"09"` 和 `"1000"` 用 `-gt` 比较。

先自己试试：不看下面，你能口述答案吗？讲完再对「完整解答」。


### 完整解答

> 🎯 **一句话**：`-gt` 是整数比较，非数字/前导零/误用字符串会反直觉；阈值用 `(())` 或先算术赋值。

```bash
conn_count=$(ss -ant | awk '/ESTAB/ {c++} END{print c+0}')
if (( conn_count > 1000 )); then
  echo "high conn=$conn_count"   # ← 输出连接数超阈值
fi
```

`(( 08 > 7 ))` 可能八进制报错——`conn_count=$((10#$conn_count))` 强制十进制。版本号比较别用字符串 `<`，用 `sort -V` 或专用库。

### 再追问

- 浮点比较？——`bc` 或 Python，Shell 整数够用就别硬上。

## Q4

**★★★★☆｜日志轮转前为什么要 `-f`、`-s` 组合？只写 `-e` 够吗？**

**覆盖**：必会 · 常用 ｜ **对应**：知识点 [四、三类测试：数值 · 字符串 · 文件 ⭐](知识点.md) · [生产模板 🔧](知识点.md)

### 场景

轮转脚本对空日志 `cp` 后 `: >` 清空，误对不存在路径创建空文件。

先自己试试：不看下面，你能口述答案吗？讲完再对「完整解答」。


### 完整解答

> 🎯 **一句话**：`-e` 只保证存在；`-f` 排除目录/设备；`-s` 保证非空才值得轮转。

```bash
[[ -f "$log" && -s "$log" ]] || { echo "skip"; exit 0; }
```

`-e` 对目录也为真——直接 `cp` 目录取决于实现，逻辑混乱。符号链接用 `-L` 追链。

## Q5

**★★★★★｜写 curl 健康检查：`200` 成功，`5xx` 失败并 exit 1，其它 warn。**

**覆盖**：必会 · 常用 · 常考 ｜ **对应**：知识点 [四、三类测试：数值 · 字符串 · 文件 ⭐](知识点.md) · [生产模板 🔧](知识点.md)

### 场景

K8s readiness 外挂脚本，3 秒超时，失败要写 stderr 给 systemd。

先自己试试：不看下面，你能口述答案吗？讲完再对「完整解答」。


### 完整解答

> 🎯 **一句话**：`[[ == ]]` 判 200；`[[ =~ ^5 ]]` 或 `case` 判 5xx；curl 失败用 `|| echo 000`。

```bash
URL=${1:?}
code=$(curl -s -o /dev/null -w '%{http_code}' --max-time 3 "$URL" || echo "000")

if [[ "$code" == "200" ]]; then
  echo "ok"
  exit 0
elif [[ "$code" =~ ^5 ]]; then
  echo "server error: $code" >&2
  exit 1
else
  echo "warn: $code" >&2
  exit 0   # 或 2，看监控约定
fi
```

### 再追问

- `000` 表示什么？——curl 超时/连不上，不是 HTTP 码。

## Q6

**★★★★☆｜用 `case` 实现：命令 `restart|status|logs` 分发，未知命令 exit 1。**

**覆盖**：必会 · 常用 ｜ **对应**：知识点 [六、多路分发：`case` ⭐](知识点.md) · [生产模板 🔧](知识点.md)

先自己试试：不看下面，你能口述答案吗？讲完再对「完整解答」。

### 完整解答

> 🎯 **一句话**：`case "$1" in` 多模式 `|`，每支 `;;`，默认 `*)`。

```bash
cmd=${1:?}
case "$cmd" in
  restart|status|logs)
    svc=${2:?svc required}
    # dispatch...
    ;;
  *)
    echo "unknown: $cmd" >&2
    exit 1
    ;;
esac
```

漏 `;;` 会穿透执行下一分支——diff review 重点。

## Q7

**★★★★☆｜`if grep ERROR app.log` 和 `if grep -q ERROR app.log` 差在哪？**

**覆盖**：常用 · 常考 ｜ **对应**：知识点 [五、流程控制：`if` · `elif` · `else` ⭐](知识点.md)

### 场景

有人用 `if grep ERROR huge.log` 导致 cron 邮件里塞满匹配行。

先自己试试：不看下面，你能口述答案吗？讲完再对「完整解答」。


### 完整解答

> 🎯 **一句话**：`if grep` 测的是**退出码**；无 `-q` 时匹配行仍打印到 stdout；`-q` 静默只要码。

```bash
if grep -q ERROR app.log; then
  echo "has errors"
fi

# 期望「没有 ERROR」
if ! grep -q ERROR app.log; then
  echo "clean"
fi
```

`grep` 无匹配返回 1——在 `if` 条件位不算 `set -e` 失败。

## Q8

**★★★★☆｜`mkdir -p dir && touch dir/f || rm -rf dir` 有什么问题？**

**覆盖**：常考 · 常用 ｜ **对应**：知识点 [七、短路：`&&` 与 `||` 🔥](知识点.md)

### 场景

部署脚本想「建目录失败就删目录」——逻辑反了。

先自己试试：不看下面，你能口述答案吗？讲完再对「完整解答」。


### 完整解答

> 🎯 **一句话**：`||` 在 `mkdir` **成功**时不会跑 `rm`；`mkdir` 失败才会删——若 `dir` 已存在部分文件会误删。

复杂逻辑改 `if`：

```bash
if ! mkdir -p "$dir"; then
  echo "mkdir failed" >&2
  exit 1
fi
touch "$dir/f" || { echo "touch failed"; exit 1; }
```

`A && B || C` 不是 if-then-else 通用替代——`B` 失败会意外跑 `C`。

## Q9

**★★★★★｜`kubectl apply` 后如何正确读 `$?`？`exit 300` 实际返回多少？**

**覆盖**：核心 · 必会 ｜ **对应**：知识点 [八、退出码 `$?` 与 `exit` ⭐](知识点.md)

### 场景

```bash
kubectl apply -f deploy.yaml
echo "done"
if [[ $? -ne 0 ]]; then ...
```

先自己试试：不看下面，你能口述答案吗？讲完再对「完整解答」。


### 完整解答

> 🎯 **一句话**：`$?` 只反映**上一条**命令——中间插 `echo` 就丢了；立刻 `rc=$?` 或 `if kubectl ...; then`。

```bash
if ! kubectl apply -f deploy.yaml; then
  exit 1
fi

# 或
kubectl apply -f deploy.yaml
rc=$?
[[ $rc -eq 0 ]] || exit "$rc"
```

`exit 300` → 300 % 256 = **44**。函数 `return` 同理。

## Q10

**★★★★★｜设计发布 gate：ready 副本 < 80% 失败，缺环境变量立即失败。**

**覆盖**：必会 · 常用 · 常考 ｜ **对应**：知识点 [生产模板 🔧](知识点.md)

### 场景

蓝绿切流前脚本检查 `deployment/login-svc` ready 比例。

先自己试试：不看下面，你能口述答案吗？讲完再对「完整解答」。


### 完整解答

> 🎯 **一句话**：`${var:?}` 早失败；`jsonpath` 取 ready/desired；`(())` 算百分比。

```bash
NS=${NAMESPACE:?}
DEPLOY=${DEPLOYMENT:?}
MIN=${MIN_READY_PCT:-80}

ready=$(kubectl get deploy "$DEPLOY" -n "$NS" -o jsonpath='{.status.readyReplicas}' 2>/dev/null || echo 0)
desired=$(kubectl get deploy "$DEPLOY" -n "$NS" -o jsonpath='{.spec.replicas}')
ready=${ready:-0}

(( desired > 0 )) || { echo "invalid replicas"; exit 1; }
pct=$(( ready * 100 / desired ))
(( pct >= MIN )) || { echo "ready ${pct}% < ${MIN}%"; exit 1; }
echo "gate ok ${ready}/${desired}"
```

### 再追问

- `readyReplicas` 空？——当 0 处理，避免空串算术错误。

## Q11

**★★★★★｜读代码：找出所有条件测试错误并改写。**

**覆盖**：核心 · 必会 · 常考 ｜ **对应**：知识点 [必会 · 常考](知识点.md) · 全章

### 场景

```bash
if [ $ENV = "prod" ]; then
  if [ $DISK -gt 90 ]; then
    alert
  fi
fi
if grep "ERROR" /var/log/app.log; then
  exit 1
fi
```

先自己试试：不看下面，你能口述答案吗？讲完再对「完整解答」。


### 完整解答

> 🎯 **一句话**：变量未引号；`DISK` 应用 `(())`；第二段若意图「有 ERROR 才退出」逻辑对但应 `-q`。

```bash
if [[ "$ENV" == "prod" ]]; then
  disk=$(df -P / | awk 'NR==2 {gsub(/%/,""); print $5}')
  if (( disk > 90 )); then
    alert
  fi
fi
if grep -q ERROR /var/log/app.log; then
  exit 1
fi
```

## Q12

**★★★★☆｜`(( ver >= 08 ))` 为什么可能报错？版本 `08` 怎么比？**

**覆盖**：常考 · 必会 ｜ **对应**：知识点 [四、三类测试：数值 · 字符串 · 文件 ⭐](知识点.md) · [原理讲透](知识点.md)

先自己试试：不看下面，你能口述答案吗？讲完再对「完整解答」。

### 完整解答

> 🎯 **一句话**：`08` 被当八进制，非法位报错；强制十进制 `10#08` 或去前导零。

```bash
ver=08
(( ver >= 8 ))              # ← 可能报错：value too great for base
(( 10#$ver >= 8 ))          # ← ok，强制十进制
```

语义版本 `v1.10` vs `v1.9` 用 `sort -V`，别用 `[[ < ]]`。

## Q13

**★★★★☆｜`[[ $f == *.log ]]` 会读当前目录吗？和 `echo *.log` 有何区别？**

**覆盖**：常考 · 必会 ｜ **对应**：知识点 [原理讲透](知识点.md)

先自己试试：不看下面，你能口述答案吗？讲完再对「完整解答」。

### 完整解答

> 🎯 **一句话**：`[[ == *.log ]]` 是**字符串模式**（case 风格），不读目录；`echo *.log` 是路径 glob。

```bash
f=access.log
[[ $f == *.log ]] && echo yes    # ← yes（字符串模式匹配）

f=access.txt
[[ $f == *.log ]] || echo no     # ← no（模式不匹配）
```

右侧加引号 `'*.log'` 则变字面相等，通常不匹配。

## Q14

**★★★★☆｜笔试：判断对错并一句话纠正。**

**覆盖**：必会 · 常考 ｜ **对应**：知识点 [必会 · 常考](知识点.md)

### 题目

1. `[` 和 `test` 是两个不同程序
2. `[[ $a = $b ]]` 在 bash 里合法
3. `-eq` 可以比较 `"3.14"` 和 `3`
4. `if foo=bar` 会赋值再测试
5. `case` 分支不需要 `;;` 也会停
6. `$?` 可以隔十行仍表示很久以前那条命令的退出码

先自己试试：不看下面，你能口述答案吗？讲完再对「完整解答」。

### 完整解答

> 🎯 **一句话**：1 错同程序 2 对 3 错整数 4 错测命令名 5 错会穿透 6 错只反映上一条。

1. **错**——`[` 是 `test` 的硬链接/内置别名。
2. **对**——bash `[[` 字符串比较。
3. **错**——整数专用；浮点换工具。
4. **错**——`if` 后 `foo=bar` 是运行命令 `foo=bar`（环境前缀），不是 `if` 赋值测试。
5. **错**——漏 `;;` 会 fall-through。
6. **错**——任何命令都会覆盖 `$?`，立刻保存。
