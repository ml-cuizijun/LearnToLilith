## Q1

**★★★★★｜配置热更、脚本、二进制、资源、强更怎么分？热更和停服更分界三句？**

**覆盖**：核心 · 必会 · 常考 ｜ **对应**：知识点 [六、热更：五类更新与可逆性](知识点.md)

### 场景

群里喊「热更一下」。有人 reload 配置，有人滚 battle Deployment，有人在切 CDN 指针。没人说改的是哪一类。

先自己试试：不看下面，先口述一遍你的答案，再往下对。

### 完整解答

> 🎯 **一句话**：先分五类，分界看进程在不在、端听不听、回滚能否加载旧 version。

配置 reload 进程在；脚本热更进程在但房间可能脏；二进制换 digest 进程没了要摘流；资源靠 CDN 指针拉差异包；强更靠 min 挡不兼容端。三句分界：进程还在不在、已装端听不听、回滚是加载旧版还是只能向前修。

> ⚠️ **别混**：五类回滚不是一个按钮——配置、指针、镜像 undo、降 min+双协议、数据回档各不同。

> 📝 **面试**：开口先分五类，再谈灰度和回滚；不要因为怕停服把必须强更的协议改成热补丁。

### 再追问

脚本热更了战斗公式，进行中的局怎么办？——按房间切版本或强制结算；一半新公式一半旧公式会结算争议。

## Q2

四元组里哪一项不能漂。


**★★★★★｜变更单要钉死什么？为什么禁 latest？**

**覆盖**：核心 · 必会 ｜ **对应**：知识点 [二、打包：四元组钉死](知识点.md)

### 场景

变更单写「跟测试服一样」。线上 battle 是 `:latest`，配置有人 scp，CDN 指针和 min 说不清。

先自己试试：不看下面，先口述一遍你的答案，再往下对。

### 完整解答

> 🎯 **一句话**：钉 digest、配置 version、资源指针、min 四元组；禁 latest 和口头对齐。

端大版本/资源号/服配置/镜像 digest 分层，揉成一个号无法分层回滚。CI promote 同一 artifact 到预发和线上，禁止线上再改一份。

> 📝 **面试**：出问题先问坏在哪一层，再选对应回滚按钮。

### 再追问

合服前四元组怎么用？——两服 digest、配置 version、协议必须一致，否则映射 dry-run 不跑（[06](../06-开服合服/)）。

## Q3

CDN 预热与切指针。


**★★★★★｜资源发布顺序？差异包靠什么？先切指针会怎样？**

**覆盖**：核心 · 必会 · 常考 ｜ **对应**：知识点 [三、CDN：差异包、预热与切指针](知识点.md)

### 场景

文件还在上传 40%，`version.json` 已切。源站带宽打满，登录监控仍绿。

先自己试试：不看下面，先口述一遍你的答案，再往下对。

### 完整解答

> 🎯 **一句话**：上传→预热 HIT→服务端兼容→切指针；差异包靠 manifest 逐文件 hash 比对；先切指针=全球回源。

客户端拉小指针 `version.json`（短 TTL），对比本地 manifest 只拉 hash 变了的文件。文件 URL 带 content hash、长 TTL + immutable。登录绿、下载红是 CDN 事故，不是登录挂了。失败指针打回已预热版本，不删源站新文件。

> ⚠️ **别混**：指针短 TTL、文件 hash 长 TTL——不能一样长。差异包是逐文件 hash 比对，不是整包版本号递减。

### 再追问

部分地区新部分旧？——指针缓存分裂或海外未预热；查版本分布双峰和分 region HIT（[08](../08-CDN与资源更新/)）。

## Q4

差异包失败怎么认。


**★★★★★｜何时必须强更？min 放哪？只降 min 够吗？**

**覆盖**：核心 · 必会 · 常考 ｜ **对应**：知识点 [四、强更：min 与双协议](知识点.md)

### 场景

改枚举含义已上线。min 写在 battle 进程。老端能登录，进战斗才炸。

先自己试试：不看下面，先口述一遍你的答案，再往下对。

### 完整解答

> 🎯 **一句话**：改含义/删必填/改握手必须强更；min 放登录/目录；回滚要先双协议再降 min。

只加 optional 可兼容。强更两段抬闸：过审→CDN→双协议→建议更新→覆盖率够再抬 min。

> 📝 **面试**：检票在大厅（目录），不在进房间时才查。

### 再追问

已抬 min 但服务端不认老协议？——先恢复双协议或回滚服务端，再降 min。

## Q5

强更 min 与双协议。


**★★★★★｜灰度按什么切？5% 崩溃翻倍怎么办？**

**覆盖**：必会 · 常用 · 常考 ｜ **对应**：知识点 [五、灰度：按 uid 放量与观察](知识点.md)

### 场景

按源 IP 灰度 5%。加速器出口用户 100% 新包。崩溃率相对基线 ×2.6，有人说再观察一小时。

先自己试试：不看下面，先口述一遍你的答案，再往下对。

### 完整解答

> 🎯 **一句话**：按 uid/server_id/渠道；崩溃×2 立刻停；不用新注册号 alone 测兼容。

观察 30～120min：崩溃、登录/进战斗、支付、CCU 相对未灰度服。资源灰度用独立指针文件。

> ⚠️ **别混**：灰度比例 ≠ 端覆盖率——抬 min 前看覆盖率。

### 再追问

能全量吗？——停灰度回滚该类，分析机型/hash/协议，不「再观察一小时」。

## Q6

灰度按 uid 放量。


**★★★★☆｜配置后台已发布，如何确认全服生效？不齐能开活动吗？**

**覆盖**：必会 · 常用 ｜ **对应**：知识点 [六、热更：五类更新与可逆性](知识点.md)

### 场景

配置中心显示已发布 version=X。20% Logic 无回执。运营要开活动。

先自己试试：不看下面，先口述一遍你的答案，再往下对。

### 完整解答

> 🎯 **一句话**：对账 `loaded_version` 回执；不齐当失败，不能开活动。

重推或摘未回执实例新进。规则分裂比晚开十分钟代价大。重复加载 X 必须幂等。

> 📝 **面试**：后台已发布 ≠ 全服生效。

### 再追问

回执一直不齐？——重推或摘新进，禁止开放活动。

## Q7

就是「热更一下」歧义现场。


**★★★★☆｜战斗服和登录服发版有何不同？能对战斗金丝雀吗？**

**覆盖**：必会 · 常考 ｜ **对应**：知识点 [六、热更：五类更新与可逆性](知识点.md)

### 场景

RollingUpdate 套到 battle。CCU 掉 25%，判负工单上来。

先自己试试：不看下面，先口述一遍你的答案，再往下对。

### 完整解答

> 🎯 **一句话**：登录可滚动，战斗摘流四步；金丝雀只对新开房间。

摘流→等空/强制结算→flush→换 digest。误滚先 `kubectl rollout pause`。

```bash
kubectl rollout status deploy/battle -n prod
kubectl rollout pause deploy/battle -n prod
```

```text
Waiting for deployment "battle" rollout to finish: 1 out of 3 new replicas have been updated...
# ← RollingUpdate 进行中 = 危险，先 pause
```

> ⚠️ **别混**：Deployment RollingUpdate 是 Web/无状态套路，不是战斗。

### 再追问

进行中房间能切 5% 流量吗？——不能，局钉旧进程；只能新匹配进新 digest。

## Q8

五类更新怎么选。


**★★★★☆｜客户端资源回滚为何难？改指针够吗？**

**覆盖**：必会 · 常用 ｜ **对应**：知识点 [三、CDN：差异包、预热与切指针](知识点.md)

### 场景

新资源致某机型闪退。指针已切 40 分钟。有人改回指针就宣布回滚完成。

先自己试试：不看下面，先口述一遍你的答案，再往下对。

### 完整解答

> 🎯 **一句话**：已装包一般只能向前修；指针只管未拉端。

回指针前确认旧包边缘 HIT。已下完差异包的设备本地文件已落地，改指针管不到。经济已产出走停活动+回档，不是发版回滚。

> ⚠️ **别混**：CDN 指针回滚（管还没拉的端）≠ 已装包体回滚（设备上文件已落地，一般不能卸）。

### 再追问

能让玩家卸新资源吗？——不能依赖；再发修复包 hash URL。

## Q9

就是 ×0.01 当没发生的坑。


**★★★★★｜掉落 ×100 顺序？能热更 ×0.01 吗？要不要全服维护？**

**覆盖**：必会 · 常用 · 常考 ｜ **对应**：知识点 [七、回滚：按可逆性止血](知识点.md)

### 场景

活动掉落多一个零。有人要热更 ×0.01，有人要立刻全服维护。

先自己试试：不看下面，先口述一遍你的答案，再往下对。

### 完整解答

> 🎯 **一句话**：回配置停产出→评估回档；不能 ×0.01；产出停不必全服维护除非整服回档。

产出还在刷就摘服/关入口。发版回滚和数据回档分开（[07](../07-停服维护与不停机更新/)/[09](../09-玩家数据备份与回档/)）。

> 📝 **面试**：经济错了先关机器（停产出），再数假钞（回档）。

### 再追问

要不要关服？——产出还在刷就摘；已停产出且不需整服回档则不必全服维护。

## Q10

按可逆性止血。


**★★★★☆｜五类更新各怎么回滚？**

**覆盖**：必会 ｜ **对应**：知识点 [七、回滚：按可逆性止血](知识点.md)

### 场景

版本日同时动了配置、指针、battle 镜像。指挥说「全体 rollback」。

先自己试试：不看下面，先口述一遍你的答案，再往下对。

### 完整解答

> 🎯 **一句话**：按类分别撤：配置 version-1、指针打回、pause+摘流+digest-1、强更双协议+降 min。

禁止四人同时改三处。灰度崩溃先停灰度再分析，不是 observe 一小时。

### 再追问

## Q11

活动窗口版本纪律。


**★★★☆☆｜热更通道怎么设计？回滚能 SSH 改文件吗？**

**覆盖**：必会 · 常用 ｜ **对应**：知识点 [六、热更：五类更新与可逆性](知识点.md)

### 场景

热更后台共用 GM 令牌。同活动点了两次加载 X。有人 SSH 改配置回滚。

先自己试试：不看下面，先口述一遍你的答案，再往下对。

### 完整解答

> 🎯 **一句话**：鉴权+审计+幂等+限频；回滚是再发加载 X-1，不是 SSH。

脚本改不了协议字段含义。发布指令与配置内容分离。独立令牌，不与玩家 GM 共用；IP 白名单 + mTLS。

### 再追问

想用热补丁改枚举避免强更？——错，必须强更+双协议路径。

## Q12

预发规范。


**★★★☆☆｜协议演进几阶段？删 v1 前看什么？**

**覆盖**：常考 ｜ **对应**：知识点 [四、强更：min 与双协议](知识点.md)

### 场景

服务端想删 v1 解析「代码太乱」。端分布显示 v1 还有 3%。

先自己试试：不看下面，先口述一遍你的答案，再往下对。

### 完整解答

> 🎯 **一句话**：五阶段到删 v1；删前 v1 占比极低且 SLI 稳，且产品 sign-off。

Phase：设计（只加 optional）→双协议→建议更新→抬 min→观察→删 v1。不能只看 min 已抬就删。

```bash
curl -s 'http://prom:9090/api/v1/query?query=sum(rate(handshake_v1_total[1d]))/sum(rate(handshake_total[1d]))'
```

```text
0.03
# ← v1 占比 3%，不能删；需 < 0.1% 且 SLI 稳定
```

### 再追问

只加 optional 字段呢？——可热更/兼容，不必强更。

## Q13

**★★★★☆｜版本日「卡在更新页」和「进服后规则错」各查什么？**

**覆盖**：必会 · 常用 ｜ **对应**：知识点 [九、作战：版本发布定责](知识点.md)

### 场景

先自己试试：不看下面，先口述一遍你的答案，再往下对。

### 完整解答

> 🎯 **一句话**：更新页查 CDN HIT/回源；规则错查 `loaded_version`；战斗不一致查房间版本。

唯一指挥官，一次只止血一项。60 秒：分类→四元组→分岔定责。

```bash
kubectl rollout status deploy/battle -n prod
curl -sI "https://res.example.com/version.json" | grep -iE 'X-Cache|HTTP/'
curl -s 'https://config/internal/receipts?version='"$CFG_VER" | jq '.missing | length'
```

> 📝 **面试**：先问火车停在哪一站。

### 再追问

## Q14

收尾到跨章。


**★★★☆☆｜活动整点能否顺便热更战斗？预发 promote 纪律？**

**覆盖**：常用 · 常考 ｜ **对应**：知识点 [八、版本纪律：活动窗口与预发规范](知识点.md)

### 场景

20:00 活动开启。19:50 策划要热更战斗公式「改个系数」。

先自己试试：不看下面，先口述一遍你的答案，再往下对。

### 完整解答

> 🎯 **一句话**：活动整点禁无关变更；战斗热更+活动=叠窗事故套餐。预发 approve 后 promote 同一 digest，禁止线上改。

可扩登录、排队、降级开关。变更单写互斥项，指挥只认一张单。预发必须跑完五类更新路径演练和回滚演练。

### 再追问

只改配置系数呢？——仍要回执齐；活动前 30min 非必要变更拒绝。
