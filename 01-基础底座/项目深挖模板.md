## B. 内存 / OOM

**背景**：`<Pod/服务>` 重启，137 / OOMKilled。

**排查**：宿主机 OOM 还是 cgroup？`dmesg` 或 `memory.events`。`free` available `<...>` 仍充足 → 容器。`memory.max` vs `memory.current`。`smaps` 涨的是 `<heap|mmap|堆外>`。Java 则核对 Xmx 与 limit。

**根因**：泄漏斜线 / 容量台阶 / Xmx=limit。  
**止血/长期**：先 `<加 limit|重启|回滚>`；长期 dump 治理 + 80% 告警。

**追问**：为什么不用 free 结案？堆外怎么证明？v1/v2 统计差什么？

## C. conntrack / 新连接失败

**背景**：节点上新建外部连接失败，**已有长连接正常**。

**排查**：`ss` 监听正常。`conntrack -C` = `<n>`，max=`<n>`，使用率 `<%>`。`timeout_established` 当时是 `<432000?>`。

**根因**：短连接 + 超长超时 / 活动登录风暴。  
**止血**：调大 max。长期：超时改 3600、告警 80%、连接池。

**追问**：为什么不永远调大 max？短连接和长连接谁更吃表？和安全组误改怎么区分？

## D. 磁盘 IO / D 状态

**背景**：P99 `<正常→异常>`，load 高，CPU idle 不低。

**排查**：`%wa` `<x>`。iostat await `<x>`ms（SSD 基线 `<5ms>`），aqu-sz `<x>`。D 进程 `<n>`，`wchan`=`<nfs|blk_mq|writeback>`。

**根因**：NFS / 云盘 QoS / 脏页 / 邻居打满。  
**止血**：停备份、懒卸载 NFS、摘盘。长期：日志本地盘、IO QoS。

**追问**：D 为什么 kill -9 无效？df≠du 你怎么处理？wa=0 盘就一定快吗？
