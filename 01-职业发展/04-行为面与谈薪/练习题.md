## Q1

**★★★★★｜讲一次最严重的线上事故，你怎么处理、怎么复盘？**

**覆盖**：核心 · 必会 · 常考

### 场景

总监：「讲一次 P0。」有人从根因 Redis 讲起，没有影响面，也没有自己的决策点。

### 完整解答

按时间线，先恢复后根因。带 MTTR 和是否复发。

```mermaid
flowchart LR
    A[发现] --> B[影响面<br/>区服 / CCU / 支付]
    B --> C[止血<br/>回滚 / 切流 / 降级，谁有权]
    C --> D[对外<br/>群时间线、运营公告]
    D --> E[根因<br/>技术 + 流程]
    E --> F[action<br/>有人、有截止日期]
    F --> G[结果<br/>MTTR、0 复发、机制还在]

    classDef a fill:#0891B2,stroke:#155E75,stroke-width:2px,color:#fff
    classDef b fill:#2563EB,stroke:#1E3A8A,stroke-width:2px,color:#fff
    classDef c fill:#16A34A,stroke:#14532D,stroke-width:2px,color:#fff
    class A,B a
    class C,D,E b
    class F,G c
```

口述骨架：「大促 / 开服前登录错误率 X%，影响 Y CCU，持续 Z 分钟。我是 on-call primary：5 分钟拉 war room，先问有没有变更，有则回滚；没有则看支付 / Redis / 网关。止血后和运营对齐公告口径。次日复盘主因是新 key 无 TTL / 配表未灰度，我推动规范、水位告警、演练。同类 0 复发。可更快的点：当时先看了 CPU，10 分钟后才看 Redis，runbook 已改顺序。」

指挥过 3 人以上、和运营对过公告，才像 7–10 年。下次同样告警还要你在场吗——答治理是否还在，不要答「我会盯得更紧」。

### 再追问

现场有人和你吵回滚吗？——对事：用错误率和 SLO，先止血。争论放到恢复后。不讲「我赢了那个开发」。

## Q2

**★★★★★｜和研发 / 上级在发布或规范上冲突，你怎么推进？**

**覆盖**：核心 · 必会 · 常考

### 场景

「赶活动要跳过预发。」你若说「我强制落地」或「那就算了」，都偏。

### 完整解答

数据 → 试点或折中 → 必要时升级用 SLO / 故障率 → 结果数字。不硬刚、不放弃规范。

1. 拿出近半年变更类 P0 占比
2. 非核心试点两周：回滚耗时下降、频率未降
3. 紧急通道保留，24h 补 Git
4. 活动：压缩预发 + 金丝雀，不是跳过
5. 对方始终拒：核心链路书面风险请老板拍板

结果全量接入，变更故障 A%→B%。承认一次没留热修通道导致反弹，后来加例外和补交时限，规范才落地。以线上结果和机制结尾，不以赢人结尾。

### 再追问

你有没有过于强硬？——用上面那次反弹承认，重点是后来机制能落地，不是性格辩论。

## Q3

**★★★★★｜举一个没人派给你、你主动推进的改进。**

**覆盖**：核心 · 必会 · 常考

### 场景

「除了值班你还做了什么？」答「领导让我做的脚本」。对方听成接单。

### 完整解答

必须非 KPI。讲发现数据、争取到的时间、阻力、结果口径。告警治理或开服自动化都合适。

「日告警 N、有效率低，无人牵头。我做两周采样，出 top 噪声；提 P0–P3 和抑制规则；找 TL 要 20% 时间；先一个业务试点再铺。结果告警量、周叫醒次数下降，且没有漏掉 P0。」功劳用时间线和文档，不靠「大家觉得我拼」。

### 再追问

业务不改阈值怎么办？——自助改阈值、用他们团队占用的无效告警占比说话、纳入发布评审。先核心链路。

## Q4

**★★★★★｜期望年包多少？为什么是 65–75 万？对方只给 62 万呢？**

**覆盖**：核心 · 必会 · 常考

### 场景

HR 第一句：「期望薪资？」有人报「最低 60 万，月薪也可以」。

### 完整解答

先确认职级和职责。一线高级 SRE 年包期望 70–75 万，结构可调；保底看 65 万档是否职级对齐。谈 Total Comp，不先报最低月薪。

按编号走（与知识点 4.4 同一条路）：

1. 不主动报数，先问级。
2. 被逼问给区间 70–75，不报最低 60。
3. 当前薪资如实。
4. 口头包拆 4 年 TC；游戏厂问项目奖 / 亏损年保底。
5. 62 万：感谢 + 兴趣 + 与高级 band 和能扛范围的差距 + 竞品约 70 + 争取 70–72，股票可灵活。
6. 职级明确中级且差距大：礼貌拒。

依据：7–10 年、能独立扛开服 / 稳定性、有量化结果、市场高级 band。例：base 3 万 × 16 薪 = 48 万，年终 4 个月期望 12 万，股票 4 年 40 万摊每年 10 万，签字费 5 万只算第一年——纸面「80 万」和 4 年均值不是一回事。

### 再追问

最低多少？——不报保底绝对值。「级别和 package 匹配的话，65–70 万我会认真看，更希望按高级 band 定。」

## Q5

**★★★★☆｜你有什么要问我们的？**

**覆盖**：必会 · 常用 · 常考

### 场景

结尾「你问我吧」。有人问加班和多久晋升。

### 完整解答

问稳定性挑战、半年目标怎么衡量、on-call 和复盘谁盯、发布 / 回滚边界。游戏岗可问开服窗口谁有否决权。不问加班、晋升、少 on-call。准备 3 个，临场选。听完用 1 句接上你的经验。职级和 band 留给 HR。

### 再追问

听完还感兴趣吗？——结合对方刚说的挑战接 1 点（活动峰值、变更事故），说你做过的对应手段，不要空夸。

## Q6

**★★★★☆｜能不能接受 7×24 on-call？**

**覆盖**：必会 · 常用 · 常考

### 场景

「我们 on-call 很猛。」答「没问题随叫随到」，像没干过。

### 完整解答

能接受，这是职责。紧接着讲可持续：告警有效、P0 有 runbook、复盘驱动、轮换公平。用你降过的告警量 / MTTR 证明不是来裸扛。反问一周几次、有无 secondary。半夜：电话升级、secondary。对方追凌晨电话：先答接受，立刻补日告警 N→M、叫醒每周 A→B。

### 再追问

on-call 太多你怎么办？——先治理无效告警和自动修复，再谈加人。只要求加人会被认为不会治理。

## Q7

**★★★★☆｜为什么离职？为什么选我们？**

**覆盖**：必会 · 常用

### 场景

「上家待一年是不是不稳定？」开始辩性格、骂领导。

### 完整解答

向前看：维护期 / 要更大容量和完整 SRE 体系。选对方：规模或窗口纪律、JD 匹配你的开服 / K8s / 稳定性，不要「因为是大厂」。不说领导差、加班、钱少。短呆：业务线调整 + 学到什么 + 下一份要对齐什么。其他 offer 可说类别，强调对本岗兴趣最高。

### 再追问

上家待一年是不是不稳定？——给具体业务变化，承诺交接周期，用 3 年规划对齐本岗，不争辩性格。

## Q8

**★★★★☆｜你犯过最大的错误是什么？**

**覆盖**：必会 · 常用 · 常考

### 场景

「没有犯过」或编成「其实是我救了场」。下一问穿。

### 完整解答

真实、有影响数字、主责写自己的流程缺失、已改、同类 0 次。DDL 未在从库验证锁表、脚本环境未隔离、配表未灰度、开服漏预检都可以。立刻止损 → 复盘承认清单缺失 → 推 gh-ost / dry-run / 双人复核 / 门禁。领导批评如实说，重点是系统已改。

### 再追问

当时想过瞒吗？——没有。瞒会使回档和公告出错，伤害更大。透明才能改流程。

## Q9

**★★★★☆｜未来 3 年规划？想做管理还是 IC？**

**覆盖**：必会 · 常用

### 场景

投 IC 岗却大谈带 20 人。或空喊转 AI。

### 完整解答

第 1 年交出告警或变更上的数字；第 2–3 年成为 1–2 条核心链路稳定性 Owner。先 IC 深度，带项目自然带人。必须能对上对方 JD。不空喊转管理或转 AI。3 年没晋升：看成长和环境，不把公司当跳板演讲。

### 再追问

如果来了还是写脚本值班？——接受 on-call 是职责；但会推动门禁和告警治理，让值班可持续。用你过去把人从救火里捞出来的数字说话。

## Q10

**★★★★☆｜多 offer，一条 78 万总包股票虚、一条 70 万但职级和开服匹配，怎么谈？**

**覆盖**：必会 · 常用 · 常考

### 场景

用 78 万去压匹配的团队到 80，话术像威胁。

### 完整解答

用更高的作锚，但表达对本团队更感兴趣，请匹配到期望档（70–75 的上沿或 72）。拆 4 年 TC：虚高股票按折现和 forfeiture 算完可能不如 70 的现金 + refresh。不要「不给到 78 我就拒」。当前司 counter：除非解决离职原因，否则向前看。

### 再追问

签字费要不要进比较？——要，但问清分期和赔付。签字费不是 4 年 TC 的稳定部分，只能补空窗。
