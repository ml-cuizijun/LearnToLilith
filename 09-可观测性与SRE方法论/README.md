# 09 可观测性与 SRE 方法论

> **定位**：把散在各章的「监控/日志/告警」收成一条**方法论主线**——出事之前怎么看见，出事之后怎么定责、怎么复盘。
> **为什么单开一章**：Metrics/Logging/Tracing 是一套体系，之前被拆在 01-22、01-23、03-19、03-20 四处，Prometheus 讲了两遍，Tracing 一处都没有，SLI/SLO 和故障复盘没有归属章。
> **原则**：只讲选型判断、指标口径、告警设计和复盘动作；不做 Prometheus 配置手册。
