## Q1

**★★★★★｜K8s 怎么调度 GPU？和 CPU 差在哪？**

**覆盖**：核心 · 必会 · 常考 ｜ **对应**：知识点 [三、Plugin 上报：Device Plugin 把卡报成可调度资源](知识点.md)

### 场景

新人写 `limits.nvidia.com/gpu: 0.3`，Pod 一直 Pending。


先自己试试，再往下看解答。

### 完整解答

> 🎯 **一句话**：Device Plugin 报 nvidia.com/gpu；整数卡或 MIG；独立池+taint；不能 0.3 卡。

```bash
kubectl describe pod vllm-0 -n ai | grep Events
# Insufficient nvidia.com/gpu  ← 真没卡，不是小数问题
```

> 📝 **面试**：Scheduler 绑带 GPU 请求和 toleration 的 Pod。

### 再追问

**Allocatable gpu: 0 查什么？**——device-plugin DaemonSet、驱动，不是删大厅。

**★★★★★｜08 和 09 各管什么？TTFT 在哪章？**

**覆盖**：核心 · 必会 · 常考 ｜ **对应**：知识点 [一、一张图：GPU 资源的一生](知识点.md)


08 vs 09 边界——全章地基。

先自己试试，再往下看解答。

### 完整解答

## Q3

**★★★★｜MIG 和 time-slicing 怎么选？活动日在线能用 time-slicing 吗？**

**覆盖**：必会 · 常考 ｜ **对应**：知识点 [四、Scheduler 绑定：整卡、MIG、time-slicing](知识点.md)


MIG vs time-slicing。

先自己试试，再往下看解答。

### 完整解答

> 🎯 **一句话**：MIG 硬件隔离可生产多租；time-slicing 无隔离，仅 dev/test，不能扛活动 SLA。

两进程 time-slicing 可能互 OOM。

### 再追问

**70B 大模型常用什么？**——整卡或多卡；小模型多租户才 MIG。

## Q6

**★★★★★｜Xid 79 GPU fallen off the bus，怎么办？delete Pod 有用吗？**

**覆盖**：核心 · 必会 ｜ **对应**：知识点 [六、故障下线：Xid、掉卡、cordon](知识点.md)


Xid 掉卡。

先自己试试，再往下看解答。

### 完整解答

> 🎯 **一句话**：cordon 节点；查驱动/硬件；delete Pod 不能修卡。


### 再追问

**Spot 回收？**——卡没了是资源问题；活动在线推理不用 Spot（09 SLA）。

## Q12

**★★★★｜宿主机 nvidia-smi 正常，Pod 内 smi 失败，先查什么？**

NVIDIA 软件栈。

先自己试试，再往下看解答。

## Q13

**★★★★｜4 卡 TP Pod Pending，集群总卡够，为什么？**

**覆盖**：必会 · 常考 ｜ **对应**：知识点 [四、Scheduler 绑定：整卡、MIG、time-slicing](知识点.md)


多卡 TP Pending。

先自己试试，再往下看解答。

### 完整解答

> 🎯 **一句话**：Scheduler 要 **同节点 N 张空闲卡**——总卡够 ≠ 单节点凑齐 4 张。
