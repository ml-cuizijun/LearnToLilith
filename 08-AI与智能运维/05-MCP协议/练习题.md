## Q1

**★★★★★｜MCP 是什么？解决什么问题？**

**覆盖**：核心 · 必会 · 常考 ｜ **对应**：知识点 [一、一张图：一次 MCP 调用的一生](知识点.md)

### 场景

「每个 Host 各写一套 Prom 胶水」。


先自己试试，再往下看解答。

### 完整解答

> 🎯 **一句话**：**MCP** = AI 连外部工具的 **标准协议**；**N×M 胶水 → N+M**；Server 写一次，多 Host 复用。

改 PromQL 口径只改 Server。

> 📝 **面试**：USB-C 类比。

### 再追问

**开放协议吗？** 是；多 Host 实现。

## Q2

**★★★★★｜Host、Client、Server 各干什么？**

**覆盖**：核心 · 必会 ｜ **对应**：知识点 [二、角色：Host / Client / Server](知识点.md)

### 场景

白板三分法。


list/call 流程，承接 Q1 三角。

先自己试试，再往下看解答。

### 完整解答

> 🎯 **一句话**：**Host** 连谁、过滤 tool、调 LLM；**Client** list/call；**Server** handler 打真实系统。

LLM 在 Host，不在 Server。

### 再追问

**Server=LLM？** 否；Server 只执行 handler。

## Q3

**★★★★★｜MCP 和 Function Calling 什么关系？**

**覆盖**：核心 · 必会 · 常考 ｜ **对应**：知识点 [五、调用链：list → FC → call → 回喂](知识点.md)

### 场景

「上了 MCP 是不是不用 FC 了」。


initialize 与能力协商。

先自己试试，再往下看解答。

### 完整解答

> 🎯 **一句话**：**FC=机制**（模型出意图→执行→回喂）；**MCP=插头**（发现 schema、跨 Host）；Client call 后 **仍 FC 循环**。

### 再追问

**没有 MCP 行吗？** 行；直接 FC schema 注册。

## Q4

**★★★★｜Tools、Resources、Prompts 区别？**

**覆盖**：必会 ｜ **对应**：知识点 [三、能力：Tools / Resources / Prompts](知识点.md)

### 场景

运维主路径用哪个？


stdio vs HTTP。

先自己试试，再往下看解答。

### 完整解答

> 🎯 **一句话**：**Tools**=call 函数（query_metrics）；**Resources**=URI 点选读（runbook）；**Prompts**=Server 模板。

Resources 不默认灌 500 页进窗口。

### 再追问

**RAG vs Resources？** RAG 自动召回；Resources 显式深读。

## Q5

**★★★★★｜stdio 和 HTTP 怎么选？**

**覆盖**：核心 · 必会 · 常考 ｜ **对应**：知识点 [四、传输：stdio vs HTTP](知识点.md)

### 场景

全员 Cursor stdio 连生产 Prom admin。


Host 过滤——安全不外包。

先自己试试，再往下看解答。

### 完整解答

> 🎯 **一句话**：**stdio**=本机子进程，权限=**笔记本用户**，个人实验；**生产共用 HTTP+SSO+最小 SA**。

生产写权限 **禁止 stdio 全员**。

> ⚠️ **别混**：stdio 方便 ≠ 生产安全。

### 再追问

**SSE？** 远程 MCP 常用 SSE/Streamable HTTP 长连接。

## Q8

**★★★★｜Server 改参数名，Host 大量 400？**

**覆盖**：常用 ｜ **对应**：知识点 [五、调用链：list → FC → call → 回喂](知识点.md)

### 场景

破坏性 schema 变更。


drift：改口径只改 Server。

先自己试试，再往下看解答。

## Q11

**★★★★｜call 401/403/429 各怎么处理？**

**覆盖**：必会 ｜ **对应**：知识点 [八、作战：MCP 排障定责](知识点.md)

### 场景

Cursor 能调 bot 不能。


只读默认。

先自己试试，再往下看解答。

### 完整解答
