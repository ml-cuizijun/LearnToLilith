# 08 AI 与智能运维

> **定位**：大厂 SRE **加分项**，不是过关生死线。  
> **考什么**：懂边界、能落地、不吹「AI 替值班」；能讲 RAG/MCP/Agent/GPU/AIOps 口径。  
> **红线**：生产数据/密钥不出域；AI 只出草稿和只读；写操作必须人审；模型会幻觉。
