## 规范

讲义体例以 `GOLDEN_STYLE.md` 为准；**默认样板** **`02-基础底座/08-TCP与UDP/知识点.md`**（§1 扫盲 → §2 架构图 → §3 核心详解 → §4 实操排障 → §6 面试锚点），分层排障对照 **`01-内核与系统`**，K8s 部署类对照 **`04-Kubernetes/02-etcd`**。

**默认**每章：**开篇主线 → 概念 → 架构 → 原理 → 落地/部署 → 配置 → 命令与操作 → 生产排障 → 必会常考 → 合上书**。

**例外（结构不同，目标一样——看完能面试）：**

| 模块 | 结构 | 复习顺序 |
|------|------|----------|
| **06 开发能力** | 面试怎么考 → 能力边界 → 语法必会 → 原理 → 生产模板 | **04 实战题 → 01 Shell → 05 正则 → 02 Python → 03 Go** |
| **09 AI** | 面试怎么考 → SRE 边界 → 原理 → 落地场景 → **口述模板** | **03 RAG → 04 FC → 05 MCP → 07 工具 → 08 GPU** |

- 先定义后解释，生产例子放在考点/排障，不要整章聊天体
- 重点用引用块标出；架构图用 mermaid；命令完整可复制
- 关键术语保留英文（K8s/SLO/RBAC/TLS/Raft/quorum）
- 正文用考察/追问，不用招聘场次叫法
- 每章：`知识点.md` + `练习题.md`（场景 + 完整解答 + 再追问）
