## 规范

讲义体例以 `GOLDEN_STYLE.md` 为准；**详度与讲解套路样板** **`01-基础底座/12-网络栈与Socket/知识点.md`**（总图 → 走读 → 名词 → 对象 → 易混专节 → 定责；难概念一例钉死）。**01 基础底座**已按此标尺改写。分层排障对照 **`04-内核与系统`**，K8s 部署类对照 **`03-Kubernetes/02-etcd`**。

**默认**每章：**开篇 → 总图+走读 → 名词 → 核心对象 → 易混专节 → 机制/命令 → 定责树 → 邻章 → 面试 → 合上书**。

**例外（结构不同，目标一样——看完能面试）：**

| 模块 | 结构 | 复习顺序 |
|------|------|----------|
| **05 开发能力** | 面试怎么考 → 能力边界 → 语法必会 → 原理 → 生产模板 | **04 实战题 → 01 Shell → 05 正则 → 02 Python → 03 Go** |
| **08 AI** | 面试怎么考 → SRE 边界 → 原理 → 落地场景 → **口述模板** | **03 RAG → 04 FC → 05 MCP → 07 工具 → 08 GPU** |

- 先定义后解释，生产例子放在考点/排障，不要整章聊天体
- 重点用引用块标出；架构图用 mermaid；命令完整可复制
- 关键术语保留英文（K8s/SLO/RBAC/TLS/Raft/quorum）
- 正文用考察/追问，不用招聘场次叫法
- 每章：`知识点.md` + `练习题.md`（场景 + 完整解答 + 再追问）
