## 追问骨架（对上新章节号）

| 追问 | 答 |
|------|-----|
| 制品怎么晋升？ | 一次构建，dev→staging→prod **同一 digest**（→ 02、03） |
| 动态 Agent 代价？ | 冷启动+拉镜像；预热/PVC。固定机留给重编译（→ 02） |
| Terraform state？ | 远程+锁；plan 必审 destroy；禁止控制台改（→ 05） |
| GitOps 回滚？ | revert Git + sync，不是只 undo（→ 09） |
| 发布怎么既快又安全？ | 分级：标准变更自动，prod 窗口+金丝雀业务 SLI（→ 02、10） |
| 幂等为什么重要？ | 可重复才可回滚；Ansible 二次 changed=0，TF plan 无意外（→ 04、05） |
